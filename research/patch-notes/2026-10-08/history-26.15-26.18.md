# 26.15~26.18 공식 패치 추가 대조

조사 기준은 이전 누락 복원을 배포한 master `0cf95e24d31bbce73131f380226dab75c74081e7`이다.
협곡의 챔피언·아이템·룬·게임 체계를 조사했다. 다른 모드·스킨·일반 버그 수정 목록은 제외하며,
챔피언 밸런스 항목 안의 동작 변경·버그 수정은 보존한다.
같은 패치의 추후 핫픽스 갱신과 26.14 이전의 공식 원문 보완은 이번 범위에 없다.

## 비교 결과

| --- | --- | --- | ---: |
| 26.15 | 8 / 1 / 0 | 11 / 3 / 1 | 69 |
| 26.16 | 33 / 6 / 0 | 7 / 10 / 5 | 49 |
| 26.17 | 7 / 1 / 0 | 14 / 2 / 0 | 32 |
| 26.18 | 8 / 0 / 0 | 11 / 1 / 0 | 30 |

26.15는 카이사·마오카이·리븐, 요새파괴자·경계와 다재다능이 없었다.
벨베스의 대규모 조정도 기존 11개 수치로는 대부분의 계수·조건·동작 변경을 표현하지 못했다.
스냅샷의 자원 필드 변화는 원문에서 설명하지 않는 숫자 차이로 남기고 공개 보고서는 공식 변경을 쓴다.

26.16은 그웬·나서스, 월식·루난의 허리케인·스테락의 도전·태양불꽃 방패·주문투척자의 신발이 없었다.
기민한 발놀림·칼날비, 정글 소환수·서포터 퀘스트도 누락했다.
원거리 딜러 28종의 공통 마법 저항력 조정은 원문처럼 공통 목록과 트리스타나 별도 수치로 묶었다.
기존 챔피언 수가 33종이었던 이유는 이 공통 마법 저항력 수치가 챔피언별로 나뉘었기 때문이다.
공식에 없는 건메탈 군화 수치 변화는 원본 스냅샷에 보존하며 공식 변경으로 표시하지 않는다.

26.17은 그레이브즈·이렐리아·나서스·쓰레쉬·트런들·야스오·요네와 폭풍갈퀴가 없었다.
르블랑의 일반 W·모방 RW, 베인 W와 치명타 관련 변경도 누락했다.
키아나 Q는 내부 원소별 데이터 네 경로의 같은 피해량 변화가 중복 표시됐다.
공식의 피해량·계수 두 행으로 표시해 같은 피해량 네 행이 반복되지 않게 했다.

26.18은 카사딘·자헨·제리와 구인수의 격노검이 없었다.
카시오페아는 기존 Q 피해량·E 마나 2개 수치만 있던 것을 패시브·Q·E·R의 10개 공식 행으로 보완했다.
에코 Q 계수, 마스터 이 R 이동 속도, 비에고 패시브의 전체 계수와 자헨 부활 시 쿨타임 규칙도 보존한다.

숫자 비교 항목과 공식 문장은 집계 단위가 다르므로 기존 수치 123개와 공식 180행의 차이를
그대로 누락 건수로 계산하지 않는다. 패치별 완전 누락 대상·기존 수치·출처·보정 내역은
[history-audit.json](history-audit.json)에 보관한다.

## 추가 원인과 수정

등록된 숫자 키만 수집하는 기존 원인은 네 패치에도 해당했다. 다음 경계도 보완했다.

- 대만 원문은 제목을 `li` 안에 넣거나 목록을 중첩했다. 정규식은 제목을 삼켜 다른 모드의
  내용까지 이전 아이템에 붙였다. HTML 트리를 따라가며 제목과 실제 변경 행을 별도로 읽는다.
- 26.16 중국어 갈라진 하늘은 회복량과 체력을 한 `li`에 합쳤다. 구조화된 제목별로 나누고,
  구분할 수 없는 여러 화살표가 있으면 조용히 합치지 않고 실패한다.
- 26.15의 Alistar와 Jade_Alistar처럼 모드별 동명 챔피언이 있다. 정확한 정식 ID를 우선하고
  이름만으로 여러 챔피언이 매칭되면 실패한다.
- 리븐 R의 바람 가르기와 르블랑 RW의 모방 왜곡은 기본 R 제목으로 합치지 않는다.
- 천 단위 쉼표·수량을 풀어 쓴 표현 때문에 같은 번역 수치가 불일치로 처리되던 문제를 정규화했다.
  가격·재시전 간격·시전 후 경직 증가를 상향으로 보던 방향 규칙도 수정했다.
- 아이템 효과의 지속시간을 첫 기본 능력치인 체력에 연결하던 아이콘 오류도 수정했다.
  기본 능력치는 항목 이름이 일치할 때만 연결하며 효과의 숫자가 우연히 같아도 아이콘을 붙이지 않는다.

## 공식 원문의 결함과 보정

26.15 대만 공식 원문은 벨베스 R의 비전투 이동 속도 제거 행을 누락했다. 영어와 한국어에
모두 있는 행을 중국어로 보완했다. 26.18 대만 원문 자헨 Q2의 변경 전 첫 랭크는 5로,
영어·한국어의 25와 다르다. 다른 랭크·계수는 유지하고 25로 보정했다.

`localizationCorrections`에는 원문 값·보완 값·위치·이유를 보관한다. 원문과 SHA-256은
그대로 유지하고 검증·화면 출력에서만 보완한다. 화면 하단에도 보완 사실을 표시한다.
26.16의 Sunfire Cape라는 이전 이름은 공식 조합비 증가와 DDragon 3068의
600→700, 총비용 2700→2800을 대조해 Sunfire Aegis에 연결했다.

## 재생성·검증

```bash
npm run generate-patch-notes -- 26.14 26.15 --official
npm run generate-patch-notes -- 26.15 26.16 --official
npm run generate-patch-notes -- 26.16 26.17 --official
npm run generate-patch-notes -- 26.17 26.18 --official
```

숫자 원본·스냅샷은 변경하지 않는다. 데이터 검사는 새 네 패치뿐 아니라 공식 원문이 있는
26.15~26.20 전체 255행의 언어별 결과·출처·완전성을 확인한다. 브라우저 검사는 각 패치의
새 대상·스킬 상세·공식 링크·게임 체계·보정 안내와 3언어·모바일·PC 가로 넘침을 확인한다.

최종 로컬 검증은 Node 테스트 1,442개·패치 브라우저 테스트 16개가 모두 통과했다.
TypeScript·ESLint·프로덕션 빌드·평가 inventory 검사도 통과했다. 320·1440px,
3언어와 밝은·어두운 테마를 확인했으며 PC 체계 화면과 모바일 출처 안내를 직접 확인했다.
26.19·26.20 공개 보고서와 모든 숫자 원본·스냅샷은 기준 커밋과 바이트 단위로 동일하다.
