# 25.1~26.14 전체 공식 패치 대조

기준 master는 `becad6e275cc423cfe256280f49218bb614ea41e`다. 25.1~25.24와
26.1~26.14, 총 38개 패치의 한국어·영어·대만 중국어 공식 문서 114개를 추가 대조했다.
앞서 완료한 26.15~26.20을 합쳐 공개 기록 44개 모두 공식 원문을 사용한다.

## 결과와 범위

- 새로 보완한 38개 패치: 공식 변경 2,470행.
- 전체 44개 패치: 공식 변경 2,725행, 화면 표시 2,729건.
- 추가 원문 보정: 행 14건, 대상 3건. 번역 표현 차이 69건은 두 원문과 이유를 고정해 승인했다.
- 이전 보고서에서 통째로 빠졌던 챔피언 대상 350회·아이템 대상 96회를 복원했다.
  같은 챔피언·아이템이 여러 패치에 등장하므로 고유 대상 수가 아니다.

협곡 챔피언·아이템·룬·게임 체계의 초기 공지를 조사했다. 챔피언 밸런스 항목 안의
버그 수정은 포함한다. 다른 모드, 별도 일반 버그 수정, 스킨·클라이언트 공지,
같은 패치의 추가 공지·핫픽스 갱신은 범위 밖이다. 숫자 비교 항목과 공식 문장의
집계 단위가 달라 두 행 수의 차이를 누락 건수로 취급하지 않는다.

패치별 기존/현재 집계, 복원 대상, URL·SHA-256, 영역 분류, 보정 전후·이유는
[history-full-audit.json](history-full-audit.json)에 보관했다. 원래 숫자 원본과
스냅샷은 변경하지 않았다. 원문 `articles`는 보정하지 않고 별도 보정 데이터만 적용한다.

## 공통 원인과 수정

등록한 수치 키만 비교하던 과거 보고서는 동작·조건·시즌 개편을 표현하지 못했다.
26.1의 역할 퀘스트·정글·오브젝트·시야·미니언·포탑·아이템 개편은 523행으로 보존한다.
25.1의 장화 업그레이드도 각 장화·카시오페아 제목을 유지한다.

소급 수집에서 다음 파서 문제도 확인했다.

- Arena/ARAM/Swiftplay가 Champions/Items/Systems 제목과 ID를 재사용한다.
  모드 안의 모르는 중간 제목 뒤에서도 모드 문맥을 유지하고 협곡으로 되돌아가지 않는다.
- 시즌별 별도 H2, ID 없는 챔피언 소개, 변경된 현지화 이름은 일반 목록과 모양이 다르다.
  공통 제목 분류와 영어·번역의 공유 스킬 이미지로 대상을 식별한다.
- 닫히지 않은 H3/strong은 다음 대상이나 목록을 태그 안에 가둔다.
  설명을 챔피언 이름으로 오인하지 않고 내부 제목·목록을 계속 순회한다.
  이 수정으로 26.5의 리 신도 세 언어에서 정상 수집된다.
- 역할 퀘스트의 진행·보상은 같은 수준의 제목이다. 상단·정글 등 직전 역할을
  붙여 한 체계 안의 독립된 묶음으로 표시한다.
- 영어 Q1, P, WW/QE, Human Q, Q (Mounted) 같은 슬롯 표기를 인식한다.
  재사용·변신·모방의 스킬 제목은 기본 스킬과 무조건 합치지 않는다.
- 문장 안의 괄호 콜론·6:00 타임스탬프는 항목 구분 콜론으로 자르지 않는다.
  강조만 있는 제목, 문장형 화살표, 괄호 안의 부가 비교도 원문을 유지한다.
- 공식의 아이템 이름과 동일한 모드용 접두사 ID가 있어도 기본 ID를 우선한다.
  삭제 아이템만 직전 스냅샷으로 이름을 보완한다. 현존 아이템에 과거 동명 ID를 추가하지 않는다.

26.1 폭풍갈퀴의 과거 ID 3097은 현행 이미지 자료에 없었다. 생성기가 현행 이미지가
없는 과거 아이템만 당시 DDragon에서 받아 패치별 WebP로 보관하고, UI와 오프라인
재생성도 같은 보관 이미지를 사용한다. 전체 보고서의 아이템 이미지 존재 여부도 검사한다.

2025년 초기 URL의 `25-s1-1`, `25-s1-2`, `2025-s1-3`도 일반 URL 규칙으로 해석한다.
패치 번호별 조건문은 추가하지 않았다.

## 공식 원문의 오류와 근거

- 26.13 중국어 아펠리오스 Q: 화살표 없이 합쳐진 이전/현재 배열을 분리했다.
- 26.11 중국어 제국의 명령: 조합비 700→650, 이전 총비용 2200→2250으로 보정했다.
  영어·한국어가 일치하고 `850+900+500=2250`, `850+900+650=2400`으로 확인된다.
- 26.11 중국어 카사딘: W에 Q 쿨타임이 복제되어 있었다. W 제목과 기본 마법 피해
  20→25 (+10% AP)를 복원했다. 다른 두 공식 문서와 보관 CDragon의
  `NetherBlade/values/PassiveBaseDamage`가 일치한다. W의 대만 이름은
  [공식 DDragon](https://ddragon.leagueoflegends.com/cdn/16.11.1/data/zh_TW/champion/Kassadin.json)으로 확인했다.
- 26.8 영어 자이라: 불완전한 문장을 다른 두 원문의 “1레벨에 W를 배울 수 없음”으로 보완했다.
- 26.3 한국어 에코: 뒤집힌 패시브 AP 계수 80→90을 90→80으로 보정했다.
  영어·중국어와 26.2/26.3 `EkkoPassive/ThreeHitDamage` 계수 0.9→0.8이 일치한다.
- 26.1 영어 엘리스: `105155`를 두 원문과 같은 `105/155`로 분리했다.
- 26.1 영어·한국어 전령: 이전/현재 사이 콜론을 분리해 주변 챔피언에 따른
  200~600골드 → 처치자 100골드로 표시한다. 중국어는 이미 화살표로 구분한다.
- 26.1 중국어 트린다미어: 최대 추가 공격력 배열을 잃은 체력 비례 계수로 잘못
  변환한 문장을 영어·한국어의 최대 추가 공격력과 잃은 체력 조건으로 보정했다.
- 26.1 중국어 공생형 밑창·경계의 와드석: 다른 두 언어에 있는 삭제 대상을 추가했다.
  대만 이름 共生之足·警覺視石은 [직전 DDragon](https://ddragon.leagueoflegends.com/cdn/15.24.1/data/zh_TW/item.json)의 3010·4643으로 확인했다.
- 25.24 중국어 자헨 Q: 쿨타임 배열을 9/8/7/6/5 → 10/9/8/7/6으로 보정했다.
  다른 두 문서와 원본 쿨타임의 실제 랭크 인덱스 1~5가 일치한다.
- 25.22 중국어 아우렐리온 솔: 잘못 들어간 마나 소모량 대신 두 원문의 Q 폭발 피해를 복원했다.
  이 패치의 보관 숫자 원본은 별도 이동 속도만 확인하므로 피해 보정은 두 공식 문서를 근거로 한다.
- 25.22 중국어 볼리베어: 방어력 55 오타를 35로 보정했다. 다른 두 문서와 원본 `stats/armor`가 일치한다.
- 25.13 중국어 피들스틱: W의 `150 180`을 `150/180`으로 구분했다. 숫자 집합만
  비교하면 놓치던 오류다. 3개 이상 값의 랭크 배열은 숫자 순서도 검증한다.
- 25.1 중국어: 근접 미니언 이전 AD의 80을 80.2로 보정하고, 승리의 아이오니아
  장화 가속 +5%를 고정 가속 +5로 보정했다. 다른 두 원문을 근거로 한다.

카시오페아의 대만 패시브명 致命節奏는 실제 공식 이름이다.
[당시 DDragon](https://ddragon.leagueoflegends.com/cdn/15.1.1/data/zh_TW/champion/Cassiopeia.json)과
[공식 챔피언 페이지](https://www.leagueoflegends.com/zh-tw/champions/cassiopeia/)를 확인해 그대로 유지했다.

## 반복 작업을 줄이는 절차

```bash
# 색인 전체를 보관 자료만으로 재생성해 공개 결과와 대조
npm run patch-notes:audit

# 모든 패치 검증이 통과한 뒤 보고서와 스킬 자료를 일괄 갱신
npm run patch-notes:audit -- --write

# 새 패치 수집, CI도 같은 명령을 사용
npm run generate-patch-notes -- --current
```

과거 아이템 이미지와 시즌 노트가 오프라인에서도 표시되는 브라우저 검사도 통과했다.

공통 파서·생성기를 수정한다. 공식 문서의 실제 오류만 검토 후 데이터로 남긴다.
새 미분류 영역, 언어별 행·수치 차이, 랭크 배열 순서 차이는 배포 전에 실패한다.
이미 승인한 표현 차이는 정확한 두 원문·위치·이유에만 적용한다. 숫자나 문장이
변하면 예전 승인으로 통과하지 않는다. 보정 기록을 만들기 위해 언어 전체 숫자 검증을 끄지 않는다.

전체 색인의 공식 출처·원문 행·언어·재생성 일치를 데이터 테스트에서 검증한다.
브랜치·master CI에는 전체 오프라인 audit 명령도 추가했다. 화면 검사는 시즌별
문맥 제목, 중복 대상 ID, 3언어, 320/1440px와 기존 스킬 툴팁·아이콘 동작을 포함한다.

검증: 로컬 Node 테스트 1,459개와 패치 브라우저 회귀 검사 12개가 통과했다.
`npm run type-check`, `npm run lint`, `npm run patch-notes:audit`, 프로덕션 빌드도 통과했다. 최종 실행 결과와 배포 검증은
커밋의 CI 및 연결된 Vault 조사 기록에 남긴다.
