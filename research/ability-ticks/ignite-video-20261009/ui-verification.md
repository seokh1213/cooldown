# 자료 패널 버튼 수선 검증

수선 범위는 자료 패널 머리와 채팅 머리의 버튼이다. 기존 LoL 자료·채팅 UI의 절제된 스타일을 유지하는 방향으로 구현 전 정했다. ENERGY/RHYTHM/MOTION=1/1/1. 질문과 스킬 정보가 중심이고 접기 버튼은 보조 제어다.

## 원인과 수정

실제 Chrome에서 자료 패널 버튼은 높이 28px, 중심 y=22px였고 채팅 머리 버튼은 높이 40px, 중심 y=32px였다. 서로 다른 머리 높이 때문에 중심이 10px 어긋났다. 두 버튼 모두 `PanelLeftClose`를 사용해 역할도 구분하기 어려웠다.

머리의 수직 패딩과 버튼 높이를 통일했다. 수정 후 두 버튼은 모두 높이 40px, 중심 y=32px다. 자료 패널은 오른쪽에 고정된 채팅 쪽으로 접히므로 `ChevronRight`를 썼다. 채팅 머리는 `PanelLeft`로 자료 패널 제어임을 나타내고 펼침 상태는 기존 눌림 표시와 `aria-expanded`로 제공한다. 상태별 title을 한국어·영어·중국어로 추가했다.

## 검증 근거

- 프로덕션 빌드, TypeScript 검사, ESLint 통과.
- 관련 웹 테스트 11/11 통과. 새 제어 테스트 5개와 기존 복수 스킬·자료 탭 테스트 6개다.
- 새 제어 테스트는 1280/1560px, 밝은/어두운 테마에서 버튼 중심·크기, 실제 접힘 방향, title, aria 상태, Enter/Space, 새로고침 후 접힘 복원을 확인한다. 390px에서는 기존 카드 화면 진입과 가로 넘침을 확인한다.
- 원래 실패 원인인 두 중심 차이를 1px 이내로 검사한다. 사용자 Chrome에서는 최종 차이 0px를 직접 확인했다.
- 두 아이콘과 접힌 뒤 헤더 아이콘의 실제 색상·합성 배경을 sRGB로 계산해 대비 3:1 이상을 검사한다. 키보드 포커스의 `:focus-visible`과 표시 그림자도 검사한다.
- 사용자 Chrome에서 수정된 아이콘을 스크린샷으로 검수하고 접기·펼치기를 직접 실행했다.

## Delivery Gate

PASS는 이번 수선 범위에 한정한다. 기존 제품 전체를 새로 인증한다는 뜻은 아니다.

### Hard Gate

- PASS R02: 새 UI 문구에 em dash 없음.
- PASS R03: 390/1280/1560px에서 dialog 가로 넘침 검사 통과.
- PASS R17: 통계·실적 수치 UI 추가 없음. 영상 계측값은 전후 프레임으로 보존.
- PASS R18: 추천사·사용자 수·가상 인물 추가 없음.
- PASS R23: 기존 라이브러리 glyph만 교체, 새 로고·이미지·탐색 구조 생성 없음.
- PASS R24: 탐색 링크 변경 없음.
- PASS R25: 새 텍스트 색상 없음. 변경한 아이콘의 합성 배경 대비를 각 테마에서 3:1 이상으로 검사.
- PASS R26: 두 버튼의 실제 접기·펼치기, 좁은 화면 카드 진입 검사 통과.
- PASS R27: 자료가 있을 때만 버튼을 두는 기존 조건 유지, 모바일·접힘 상태 검사 통과.
- PASS R28: FAQ 추가 없음.
- PASS R32: Enter/Space, 포커스 유지, visible focus 검사 통과.
- PASS R33: 소스 변경은 apply_patch로 수행.
- PASS R34: 실제 두 테마의 제어 동작과 대비 검사 통과.
- PASS R35: 프로덕션 빌드·웹 테스트 통과, Chrome에서 변경한 두 제어를 직접 클릭.
- PASS R36: 성능·보안 성과 문구 추가 없음.
- PASS R37: 기존 UI 수선 방향과 1/1/1 dials를 구현 전에 정함.
- PASS R38: 게임 수치를 생성하지 않고 사용자 영상의 체력 감소만 관측, 내부 타이머의 한계 명시.

- PASS R07: 배경 패턴 추가 없음.

- PASS C4: 두 테마·세 폭·키보드·저장 상태 복원 검사 통과.
