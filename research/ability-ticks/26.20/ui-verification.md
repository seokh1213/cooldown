# 틱 카드 UI 검증, 2026-10-09

검증 범위는 스킬 카드에 추가한 틱 필드와 근거 펼침·링크다. 기존 카드와 자료 패널 배치를 유지하는 수선으로, 시작 전 방향을 정했다. ENERGY=1, RHYTHM=1, MOTION=1. 선택한 스킬의 간격·횟수가 먼저 읽히고 근거 링크는 필요할 때 펼친다.

## 실제 검증

- 프로덕션 및 로컬 빌드 성공. 집중 Playwright 4/4 통과. 390/1280px, 밝은·어두운 테마, 단일 카드, 선택 행, 자료 패널, 기록 복원, 알려진/불확실/미기재 값 및 후속 질문을 검증했다.
- 근거 summary는 Enter로 접고 펼칠 수 있다. 출처 링크는 포커스를 받을 수 있고, summary·링크 모두 높이 44px 이상이다. 외부 링크는 검수한 HTTPS Wiki 문서로 연결한다.
- 사용자 Chrome 로컬 앱에서 ‘코르키 w, e 지속 틱은 어떻게되는거지?’ 및 ‘그럼 E는 몇 틱?’을 직접 입력해 카드와 채팅의 같은 수치를 확인했다. 과거 저장 답변은 변경하지 않고 새 질의로 확인했다.
- 색상은 computed style을 브라우저 Canvas sRGB로 변환하고 배경의 투명 레이어를 합성해 WCAG 대비를 계산했다. 밝은 테마 본문 15.07:1, 출처 5.74:1. 어두운 테마 본문·출처 16.81:1. 최초 어두운 출처 4.42:1은 기존 foreground 토큰으로 보완했다. [원시 측정](contrast.json).
- 틱 자체의 불확실성 및 게임 내 직접 계측 범위는 [조사 보고서](README.md)에 명시했다.

## Delivery Gate

각 PASS는 위 새 UI 범위에 한정한다. 추가하지 않은 요소는 기존 화면 전체의 인증을 뜻하지 않는다.

### Hard Gate

- PASS R02: 새 UI 문구에 em dash 없음.
- PASS R03: 390/1280px dialog의 scrollWidth ≤ clientWidth, E2E 확인.
- PASS R17: 865/136/6/723 수치는 실제 조사 JSON과 audit 실행 결과다.
- PASS R18: 추천사·사용자 수·평점 UI 추가 없음.
- PASS R23: 이미지·로고·플레이스홀더 자산 추가 없음.
- PASS R24: 탐색 메뉴 추가 없음. 근거 URL은 검토한 Wiki 문서이며 허구 목적지가 없다.
- PASS R25: 새 본문·summary·링크의 최저 대비 5.74:1, AA 4.5:1 이상.
- PASS R26: 근거 펼침·접힘, 출처 포커스·href를 실제 브라우저에서 확인.
- PASS R27: known/unknown/not_documented 및 패치·툴팁 변경 상태를 정의하고 테스트.
- PASS R28: FAQ·불필요한 안내 섹션 추가 없음.
- PASS R32: summary Enter 접기·펼치기, 링크 키보드 포커스, visible outline 및 44px 목표를 확인.
- PASS R33: UI 소스 변경은 apply_patch로 수행.
- PASS R34: 밝은 테마와 실제 html.dark 테마에서 화면·색상·답변 검증.
- PASS R35: 두 빌드 성공, 새 summary와 출처 링크의 동작·목적지 검증.
- PASS R36: 성능·보안 성과를 주장하는 문구 추가 없음.
- PASS R37: 기존 표 수선 방향, 1/1/1 dials를 정하고 유지.
- PASS R38: 게임 수치를 생성하지 않고 검수 자료를 사용, 불확실 항목은 사유 표시.

### Purpose Gate

- PASS R01: gradient·장식 glow 추가 없음.
- PASS R04: 의미 없는 아이콘 추가 없음.
- PASS R06: 기존 폰트와 text-xs 계층 사용.
- PASS R07: 배경 패턴 추가 없음.
- PASS R08: 화살표 장식 추가 없음. 기존 disclosure 표식은 펼침 동작을 나타냄.
- PASS R09: 배지 추가 없음.
- PASS R10: 유리·반투명 장식 추가 없음.
- PASS R12: 그림자 추가 없음.
- PASS R13: glow 추가 없음.
- PASS R14: 동일 스킬 행 안에서 병렬 사실과 설명을 배치, 새 카드 반복 없음.
- PASS R19: 애니메이션 추가 없음.
- PASS R22: 삽화 추가 없음.

### Liveliness Gate

- PASS L1: ENERGY 1, RHYTHM 1, MOTION 1, 수치 확인에 집중.
- PASS L2: 기존 선택 행·표·접힘 문법과 일치.
- PASS L3: 질문한 W/E 행이 시각적 초점, 근거는 하위 계층.
- PASS L4: 표제·수치·근거의 간격으로 구분, 장식선 추가 없음.
- PASS L5: 기존 primary 색상만 강조에 사용. 어두운 출처는 대비를 위해 foreground 사용.
- PASS L6: 기존 슬롯 아이콘·이름·사실의 반복 구성을 유지.
- PASS L7: 디자인 방향은 기존 카드 형식 유지로 구현 전에 선언.

### Craft Gate

- PASS C1: 스킬 설명 아래 틱 표제·사실·근거 순서로 계층 구분.
- PASS C2: 새 summary·링크 실제 동작 및 키보드 검증.
- PASS C3: 숫자·예외·근거가 실자료이며 모델의 추정 수치 없음.
- PASS C4: 작은 화면·넓은 화면·두 테마·저장 복원·후속 대화·미확인 상태 검증.
- PASS C5: 출처 링크와 불확실 이유를 바로 확인할 수 있음.
- PASS R05: 템플릿형 랜딩·장식 섹션 추가 없음.
- PASS R11: 새 radius 사용 없음.
- PASS R15: ‘지속 틱’, ‘틱 근거’는 제공 정보·동작을 구체적으로 설명.
- PASS R16: AI 홍보·과장 문구 추가 없음.
- PASS R20: LoL 챔피언 스킬과 원래 아이콘·슬롯의 정체성을 유지.
- PASS R21: 기존 사용자 테마 설정을 따름. 시스템 dark 초기화도 E2E 검증.
- PASS R29: 기존 텍스트·색상·간격 토큰 사용.
- PASS R30: 기존 제품 컴포넌트에 필요한 필드만 추가.
- PASS R31: 반복 판정은 펼침 밖에 표시하고 긴 출처만 접어 읽는 순서를 보존.
