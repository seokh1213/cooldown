## 자료와 품질 범위

- `knowledge/combo-guides.json`: 일관된 템플릿으로 편집한 원본.
- `sources.json`: 조사한 173개 콤보 페이지와 추가 활용 가이드의 수집 기록.
- 공개된 연계를 정리한 항목 331개, 스킬 설명으로 구성한 기본 연계 예시 22개. 원문 문단을 통째로 복사하지 않고 버튼 순서와 한국어 조건을 편집했다.
- 콤보 목록이 없는 8명은 활용 가이드와 현재 스킬 설명을 확인했다. 이 중 자헨은 별도 가이드에 실제 연계가 있으며, 나머지는 기본 연계 예시로 구분했다.
- 고급 점멸 애니메이션 연계처럼 근거가 부족한 내용은 추가하지 않았다. 전 챔피언 시험은 자료 선택·화면 전달을 검증하며, 게임 안에서 모든 연계를 재현했다는 의미는 아니다.
- 새 구조의 한국어 콤보를 적용했다. 영어·중국어는 기존 번역 노트를 유지하며 한국어 본문을 섞지 않는다.

## 유지와 대화 흐름

`ComboPattern`은 `id`, `title`, `keys`, `tip`, `origin`, `sourceUrl`로 고정한다. 각 챔피언은 스킬 본문 지문을 함께 기록한다. 빌드 시 **현재 패치 카드**와 지문을 비교하고, 변경되면 해당 챔피언 이름과 재검수 안내를 내며 중단한다. 검수한 원본을 갱신한 뒤 `npm run llm:bundle`로 배포 자료를 다시 만든다.

명시적 콤보 질문은 모델 없이 자료를 선택한다. 대화 기억은 챔피언과 사용할 수 없는 버튼을 저장하며, 후속 준비 상태로 갱신한다. 기존 상성·조건 대응의 플레이북 순서는 유지한다. 0.8B의 생성 실험 설정은 이번 변경에 포함하지 않았다.

## 26.20 개별 재검수 (2026-10-07)

26.20의 한국어 스킬 카드와 26.19 카드를 비교한 결과 12명의 스킬 본문이 달라졌다. [공식 패치 노트](https://www.leagueoflegends.com/en-us/news/game-updates/league-of-legends-patch-26-20-notes/)와 기존 콤보의 버튼 순서·발동 조건을 대조했다. 아래 12명만 `abilityTextHash`, `reviewedAt`, `verifiedPatch`를 갱신했다. 나머지 161명과 파일 전체의 기준 패치는 26.19로 남긴다. 컴파일러는 개별 `verifiedPatch`가 있을 때만 이를 우선하며 본문 지문 불일치는 계속 거절한다.

- 암베사 P: 추가 피해량 감소. 스킬 후 이동·강화 평타 충전 조건은 같아 기존 연계를 유지한다.
- 다이애나 W: 보호막의 추가 체력 계수 증가. 구체 적중과 Q 표식에 따른 E 초기화 조건은 같다.
- 크산테 W: 일반·총공세 피해 감소율 하향. 충전과 Q3 준비, 총공세 전후 스킬 차이를 명시한 기존 조건은 유지된다.
- 케넨 E: 종료 후 공격 속도 증가. 콤보는 W 강화 평타 준비와 표식 3개를 요구하며 특정 공격 속도 수치를 전제하지 않는다.
- 킨드레드 W/E: 몬스터 추가 피해와 E 둔화 지속시간 증가. E 3회 공격 조건은 같다. 공식 노트의 E 소형 몬스터 대상 제거도 확인했다. 기존 콤보는 적 챔피언 대상 교전이며 소형 몬스터에게 E를 추천하지 않는다.
- 릴리아 R: 스킬 랭크에 따른 수면 시간 증가. E로 패시브를 묻히고 R 졸음 뒤 진입하는 조건은 같다. 고정 수면 시간을 노트에 쓰지 않는다.
- 모데카이저 Q: 레벨 비례 피해량 증가. 패시브 3회 적중과 단일 대상 Q 조건은 같다.
- 니코 E: 피해와 강화 속박 시간 증가. 미니언을 통과해 E를 강화하는 조건은 같다.
- 스몰더 R: 회복량과 추가 공격력 계수 증가. Q/W/E 중심의 기존 콤보는 회복량을 전제하지 않는다. Q/E 중첩·치명타 계수 변경도 확인했다.
- 스웨인 W: 피해량 증가와 재사용 대기시간 감소. W 지연과 E 복귀 속박·재사용 순서는 같다.
- 탐 켄치 Q: 기본 회복량 증가. 클라이언트의 이전 랭크별 회복 수치와 공식 노트의 이전 수치가 달라 이를 같은 값으로 간주하지 않았다. 기존 콤보는 회복 수치 대신 패시브 3중첩의 Q 기절 조건을 사용한다.
- 유나라 Q: 추가 마법 피해 감소. Q 8중첩과 R 강화 형태의 E 이동 조건은 같다. 공식 노트의 W 둔화 중첩 제거도 확인했으며 기존 콤보는 둔화 중첩을 주장하지 않는다.

이 검수는 변경된 원문과 기존 연계 조건의 대조다. 게임 안에서 모든 연계를 직접 재현한 기록은 아니다.

### 상성 캐시 지문 이관

26.19 배포 캐시의 생성 시점 지문과 현행 노트 조립 결과가 이미 달랐다. 이를 그대로 필터링하면 7,262쌍 전부 제외되어 연구용 조건 원자 입력과 기존 답변이 사라진다. 이번 이관은 [쌍별 비교 기록](26.20-matchup-carry.json)의 조건을 모두 만족한 쌍만 보존한다. 세 언어의 두 챔피언 카드에서 실제 스킬·스탯이 같고, 현행 코드로 만든 26.19/26.20 재료가 SHA-256까지 같아야 한다. 모집단 변화로 달라지는 백분위·등급은 카드 비교에서만 제외하고, 최종 재료 비교에서는 제외하지 않는다. 변경된 협곡 아이템 이름을 언급한 답변도 제외한다. 그림자불꽃 한국어 설명은 같은 40% 체력 경계·20% 추가 피해를 재서술한 것으로 직접 대조했다.

원래 답변 본문은 고치지 않고 `sourcePatch: 26.19`와 이월 이유를 남긴다. 바뀐 원문을 새로 승인하거나 기존 답변 전부의 의미 검수를 마쳤다는 뜻은 아니다. 보존한 쌍도 최종 `llm:carry --force --matchups-only`로 현행 지문과 다시 비교했다. 이후에는 기존 지문 검사를 그대로 사용하며 자동 재승인 기능은 추가하지 않았다. 자동 이월은 5,838쌍이다. 닐라 대 스몰더는 별도로 현재 카드와 대조해 세 언어의 콤보·진입 타이밍·한타 세 주제만 재검수했다. 다른 다섯 주제는 복원하지 않았으며 [개별 검수 기록](26.20-nilah-smolder-review.json)을 보존한다. 최종 보존은 자동 5,838쌍과 수동 검수 1쌍이다.

## 모바일 후속 수정

모바일 헤더의 AI 모델 아이콘을 숨겼다. 서랍이 열린 동안 배경 페이지를 고정하며, 터치·휠이 내부 스크롤의 끝에서 바깥으로 전달되지 않게 한다. `visualViewport` 높이와 위치에 맞춰 서랍을 배치하고, 입력창 아래에 24px + 기기 안전 영역만큼 같은 배경색의 여백을 둔다. 닫을 때 기존 페이지 위치와 스타일을 복원한다.

재현 시험은 수정 전 모바일 AI 버튼 노출로 실패했다. 수정 후 기록 열기·선택, 짧은 목록의 스크롤 누출 방지, 긴 기록의 내부 스크롤, 화면 높이 변경, 키보드 형태의 가시 영역 변화, 입력창 하단 여백을 검사한다. 실제 휴대폰의 소프트 키보드는 사용하지 않았고 모바일 Chrome 터치 입력과 가시 영역 이벤트를 시험했다.
