## 자료와 품질 범위

- `knowledge/combo-guides.json`: 일관된 템플릿으로 편집한 원본.
- `sources.json`: 조사한 173개 콤보 페이지와 추가 활용 가이드의 수집 기록.
- 공개된 연계를 정리한 항목 331개, 스킬 설명으로 구성한 기본 연계 예시 22개. 원문 문단을 통째로 복사하지 않고 버튼 순서와 한국어 조건을 편집했다.
- 콤보 목록이 없는 8명은 활용 가이드와 현재 스킬 설명을 확인했다. 이 중 자헨은 별도 가이드에 실제 연계가 있으며, 나머지는 기본 연계 예시로 구분했다.
- 고급 점멸 애니메이션 연계처럼 근거가 부족한 내용은 추가하지 않았다. 전 챔피언 시험은 자료 선택·화면 전달을 검증하며, 게임 안에서 모든 연계를 재현했다는 의미는 아니다.
- 새 구조의 한국어 콤보를 적용했다. 영어·중국어는 기존 번역 노트를 유지하며 한국어 본문을 섞지 않는다.

## 유지와 대화 흐름

`ComboPattern`은 `id`, `title`, `keys`, `tip`, `origin`, `sourceUrl`로 고정한다. 각 챔피언은 스킬 본문 지문을 함께 기록한다. 빌드 시 **현재 패치 카드**와 지문을 비교하고, 변경되면 해당 챔피언 이름과 재검수 안내를 내며 중단한다. 검수한 원본을 갱신한 뒤 `npm run llm:bundle`로 배포 자료를 다시 만든다.

명시적 콤보 질문은 모델 없이 자료를 선택한다. 대화 기억은 챔피언과 사용할 수 없는 버튼을 저장하며, 후속 준비 상태로 갱신한다. 기존 상성·조건 대응의 플레이북 순서는 유지한다. 0.8B의 생성 실험 설정은 이번 변경에 포함하지 않았다.

## 검증

- 전체 단위·자료 시험: 2,146건 통과.
- 배포용 브라우저 전체 시험: 126건 통과. 콤보와 이전 아크샨·파이크 대화, 모바일 기록·터치·입력창, PWA 갱신 시나리오 포함.
- Chrome에서 이전 대화 복원, 목록·출처 제거, 하단 복사 완료 표시를 직접 확인.
- TypeScript 검사·로컬 빌드·전체 lint 통과. 번역 전수 검수 때 보관한 일회성 probe 실행 기록은 lint 산출물 제외 목록으로 옮겼으며, 유지하는 제품·검수 도구는 계속 검사한다.
- 화면 캡처는 `screenshots/`에 저장했다.

## 모바일 후속 수정

모바일 헤더의 AI 모델 아이콘을 숨겼다. 서랍이 열린 동안 배경 페이지를 고정하며, 터치·휠이 내부 스크롤의 끝에서 바깥으로 전달되지 않게 한다. `visualViewport` 높이와 위치에 맞춰 서랍을 배치하고, 입력창 아래에 24px + 기기 안전 영역만큼 같은 배경색의 여백을 둔다. 닫을 때 기존 페이지 위치와 스타일을 복원한다.

재현 시험은 수정 전 모바일 AI 버튼 노출로 실패했다. 수정 후 기록 열기·선택, 짧은 목록의 스크롤 누출 방지, 긴 기록의 내부 스크롤, 화면 높이 변경, 키보드 형태의 가시 영역 변화, 입력창 하단 여백을 검사한다. 실제 휴대폰의 소프트 키보드는 사용하지 않았고 모바일 Chrome 터치 입력과 가시 영역 이벤트를 시험했다.
