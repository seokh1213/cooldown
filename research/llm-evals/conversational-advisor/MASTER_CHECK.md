## 네 단계와 책임

1. `dialogueRequest.prepareDialogueRequest`: 저장된 대상·조건·현재 상성을 복원하고 요청을 준비한다.
2. `dialoguePlanner.planPreparedDialogue`: 이번 질문의 의도와 대상을 선택한다. 기본 11개 처리기는 지식 4개 → 상성 4개 → 개별 대상 2개 → 노트 1개로 묶인다.
3. `dialogueReply.assembleDialogueReply`: 조회·계산·노트·상성 답 은행으로 답을 조립하고 실제 표시한 주제를 기억에 반영한다.
4. `useAskAdvisor.recordReply`: 답변과 해당 시점의 기억을 같은 턴에 표시·저장한다.

기억 계층은 지칭·수치 조건·관점·진행 상태를 다룬다. 기본 계획기의 지식 조회·레거시 호출 경로는
계속 사용하므로 모든 판단 코드를 하나의 함수로 합친 것은 아니다. 겹치는 규칙 답과 질문 조건식,
상성 문단 선택을 공통화했다.

답 은행은 최대 8개 주제를 구분한다. 은행이 없는 쌍의 노트 조립은 기존의 조심할 것·아이템·싸우는 법
3개 칸으로 진행을 기록한다. 이 경로에서 모든 노트 문단을 하나씩 순회하도록 확장한 것은 아니다.

## 추가로 발견해 고친 회귀

- 쿨타임 조건이 남아 있으면 사거리·마나 질문까지 쿨타임을 계산하던 문제: 계산은 쿨타임 의도일 때만 적용한다.
- “제드랑 아리 궁 사거리 비교”를 쿨타임 비교로 처리하던 문제: 실제 질문·조회 항목을 비교 및 기억에 전달한다.
- 스킬 조회 뒤 룬 질문이 최근 스킬의 생략 질문으로 처리되던 문제: 명시적인 규칙 조회는 공통 계획기로 넘긴다. “감전과 어둠의 수확 쿨타임”은 둘 다 답한다.
- 내 챔피언을 말하지 않은 “피오라 W 어떻게 빼?”에 아트록스 전용 조언이 섞이던 문제: 상대·라인 조건을 충족하지 않은 노트는 제외하고, 상대법의 전체 문단을 보여준다. 일반 아이템 조건 노트는 유지한다.
- 텍스트·규칙 답이 본문과 카드 설명으로 두 번 표시되던 문제: 같은 답 본문은 한 번 표시한다.

## 실제 Chrome 확인

`모델 없이 써보기`로 앱 입력창·답변 표시·저장 복원을 확인했다.
이번 점검에서 0.8B 다운로드·추론 및 이전 74턴 품질 점수를 새로 측정하지 않았다.

- 잭스/피오라 라인전 → 팁 → 팁 → 새로고침 및 대화 복원 → 팁: 남은 칸을 이어 보여주고 소진 안내.
- 같은 상성에서 팁 → “왜?” → 팁 → 팁: 콤보의 이유로 연결하고, 이유 답에서 본 주의 사항은 다음 팁에서 제외. 마지막 안내는 한 번 표시.
- 제드 R 1랭크·가속 50: 80초 → “그럼 사거리는?”: 625 → 제드/아리 R 사거리 비교: 625/450.

- 감전 쿨타임: 20초. 두 룬 질문: 어둠의 수확 35초와 감전 20초.
- `ahri q range`: 970. 피오라 W 상대법은 특정 내 챔피언 조건 노트 없이 옆무빙 등 실제 대처 문단 표시.
- 콘솔 오류 0건. [화면 기록](master-flow-ui.txt)에 수정 과정에서 발견한 문제와 최종 답을 구분했다.

## 카드 재생성 검토

한국어 카드 기준 122개 챔피언의 내용이 달라졌으며 스킬 본문 135개, 계수 필드 59개가 바뀌었다.
계수 파서는 `(70% ~ 100%) 주문력`처럼 범위로 표기된 값을 읽고, 랭크별 목록·고정값과 함께
스탯별 최대값을 수집한다. 추가 체력과 최대 체력을 구분하며 퍼센트가 없는 일반 수치는 계수로 읽지 않는다.
이는 기존 카드의 최대 계수 계약을 보존하는 처리이고 레벨별 피해 계산기를 새로 만든 것은 아니다.

세 보정 지문 변경:

- 하이머딩거 Q: 포탑 체력 계수의 범위 표기 변경.
- 일라오이 Q: 툴팁에 빠졌던 후려치기 배율 표시 복구.
- 카타리나 P: 기본 수치와 레벨별 주문력 계수 범위 표시 복구.

[전후 변경과 보정 검토 기록](master-card-regeneration.json)을 보관한다.
카드 재생성 때문에 노트 재검토 알림이 생긴 10종(Akshan, Aphelios, Heimerdinger, Illaoi, Katarina,
Mordekaiser, Poppy, Samira, XinZhao, Yuumi)은 검토 지문을 갱신하지 않았다.
바뀐 툴팁과 노트의 영향 범위를 읽었지만, 해당 노트의 모든 게임 판정·통계·추천을 최신 패치에서
다시 검증한 것은 아니다. 카드 재생성은 완료됐고 이 10종의 노트 전체 검수는 별도 후속 작업이다.
