# 게임 약칭 회귀 확인 — 2026-10-02

## 확인 범위

`공속`, `마저`, `방어`, `아머`, `공격력`, `깡공`, `이속`, `체젠`, `체력`, `방관`, `물관`, `마관`, `치확`, `치피`, `피흡`, `흡혈`, `강인함`, `마젠`, `스가`, `스킬 가속`, `AP`, `AD` 22개를 확인했다.

- 기존 앱과 고정된 로지스틱 보조 모델을 켠 앱, 각각 새 대화와 `오공 문도 박사 18레벨 체력 비교` 직후: 총 88건.
- `appChat`에서 실제 `answerDialogue`, 기존 오프라인 판정기, 최종 응답, 카드 조회와 저장·복원을 실행했다. 외부 생성 모델은 사용하지 않았다.
- 수치 조회는 대상·항목·레벨·카드 수치·체력 재생 단위를 검사했다. 원리 질문은 해당 본문이 나오는지, 자료 없는 항목은 정확한 항목과 자료 없음 안내가 나오는지 검사했다. 잘못된 챔피언 카드가 나오는 것도 실패로 처리했다.
- 새 대화의 일반 능력치 질문은 챔피언으로 잘못 바뀌지 않는지만 검사했다. 모든 능력치의 정의 설명 품질을 평가한 것은 아니다.

문제는 게임 원리 사전의 `마관` 등을 챔피언 오타 보호에서 사용하지 않았던 것이다. `스킬 가속`의 `가속`도 가렌 오타로 바뀌었다. 수정 전에는 로지스틱 보조를 켜도 22개 모두 기존 앱과 같았다.

능력치·원리·자료 없는 능력치의 어휘를 공통 `isGameWord`에 연결했다. 기존 검색 사전에 `물관·스가·가속·치피`를 추가했다. 생명력 흡수·마나 재생·주문력 등은 인식과 수치 조회 가능 여부를 구별한다. 스킬·아이템·계수·추천 질문은 기존 자료 경로를 유지한다. 학습 가중치나 거절 기준은 바꾸지 않았다.

## 결과와 재현

- 수정 후 명시한 회귀 조건 **88/88** 통과. 발견한 문제를 고친 뒤 같은 입력을 검사한 결과이며, 새로운 독립 평가 정확도가 아니다.
- 기본 모드의 Chrome 로컬 앱에서 비교 질문 뒤 `공속 → 마저 → 방관 → 마관 → 피흡 → 스킬 가속 → AP` 7개를 연달아 입력했다. 공속 1.04/1.05, 마저 62.85/68.1과 18레벨을 확인했다. 원리와 자료 없음 응답이 나타났고 마스터 이·피즈·가렌으로 바뀌지 않았다.
- 신규 회귀 테스트 19건. 실제 별명 `마이·피즈·가렌`과 오타 `럼미 E·재이스 궁`, 흡혈 아이템·AP 스킬 계수, 단어 경계도 확인했다.
- 전체 **1,623건** 통과. `npm run type-check`, `npm run lint`, `npm run build` 통과. 기존의 600KB 번들 크기 안내는 남아 있다.

## 현재 범위

숫자로 조회하는 기본 능력치는 여전히 체력·체력 재생·방어력·마법 저항력·공격력·공격 속도·이동 속도 7개다. 관통·치명타·가속은 기존 원리 자료를 보여준다. 아이템·룬·스킬을 합친 최종 관통력·흡혈·주문력 수치는 계산하지 않는다. `마관` 응답도 마법 관통 전용 수치 설명이 아니라 기존의 일반 관통·감소 문서다. 로지스틱 실험은 여전히 개발 옵션이며 기본 앱에서는 꺼져 있다.

로컬 커밋까지 확인했으며 이 변경을 원격 푸시하거나 Pages에 배포하지는 않았다.
