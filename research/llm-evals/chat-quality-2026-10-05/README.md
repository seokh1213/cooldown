# 번역 반영 후 상담 채팅 품질 점검

패치 26.19의 승인 영어·중국어 번역을 master에 반영하고, 실제 상담 진입점과
브라우저에서 질문을 보내 점검했다. 번역 데이터 커밋은 `df20e7f7e`다.
이번 비교는 내려받는 0.8B 모델을 사용하지 않은 **앱의 오프라인 판정기** 경로다.
0.8B 모델의 현재 정확도나 전체 사용자 만족도를 측정한 결과는 아니다.

## 수정한 문제

- 영어 `As Ahri, …` 및 `… as Ahri`를 공격 속도 약어로 해석해 상성 대신 공속을 답했다.
  단일 능력치 판독과 복수 능력치 판독이 같은 문맥 제외 규칙을 사용하도록 바꿨다.
  실제 `AS` 조회와 `as at level 6` 같은 능력치 문형은 유지한다.
- 상대를 먼저 말한 `파이크 … 제가 소라카인데 …`, `… 나 파이크인데 …`에서
  내 챔피언을 뒤집었다. 명시적인 한국어 자기 소개와 서술어를 관점 표지로 사용한다.
  챔피언 이름만 나열한 불확실한 문장은 기존 처리에 남긴다.
- 노트 fallback의 영어·중국어 문구는 후속 스킬 적중을 보장하는 단정을 충분히
  걸러내지 못했다. 확인된 단정 문형을 기존 사실 점검에 추가했다.
  중국어 문장부호 뒤에 공백이 없어도 문장을 나누어 인접한 정상 문장을 보존한다.

번역 원문·승인 데이터의 지문은 바꾸지 않았다. 원문을 번역할 때의 의미 보존과
실제 답변에서 전투 결과를 보장하는 문장을 제외하는 작업은 별도로 처리한다.

## 검증

| 범위 | 결과 |
| --- | --- |
| 전체 단위·데이터 테스트 | 2,074개 통과, 실패 0 |
| 상담 브라우저 테스트 | 기존 16개와 새 다국어 3개 통과 |
| 타입 검사·린트·프로덕션 빌드 | 통과 |
| 직접 브라우저 확인 | 한국어 조건 정정, 영어 상성 문형, 중국어 콤보·번역 노출 |
| 대표 대화 | 3개 언어 24턴; 빈 답변·외국어 답변의 한글 잔류 0 |

새 브라우저 테스트는 승인된 영어 상성 답변과 아이템 이어 묻기, 중국어 콤보의
스킬 순서와 과도한 적중 보장 제외, 한국어 소라카 관점을 확인한다.
브라우저의 모델 다운로드를 건너뛰어 앱의 오프라인 판정기를 사용했다.

270턴은 기존 `research/llm-evals/kev-agent/a-set.jsonl`의 공개 질문과 정답 라벨로 비교했다.
현재 앱의 `answerDialogue`를 호출하고 매 턴 `dehydrateTurn`·`reviveTurn`으로 대화를
저장·복원했다. 앱 제공 파일을 읽도록 `/cooldown/` 자료 경로를 맞췄다.
예전 `eval-a.ts`의 단일 계획 경로 점수와 섞지 않았다.
주 담당자가 추가 24턴의 전체 답변과 주요 불일치 사례를 직접 읽었다.

| 언어 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| 한국어 | 62/88 | 72/88 |
| 영어 | 59/91 | 70/91 |
| 중국어 | 65/91 | 65/91 |
| 전체 | 186/270 | 207/270 |

기존 라벨과 갈래·대상·시점·주제가 일치한 턴은 **69.0% → 76.7%**다.
같은 질문·라벨을 유지했고 21턴 개선, 퇴보 0턴을 확인했다.
이 수치는 번역 정확도나 게임 조언의 사실 정확도가 아닌 **질문 해석의 라벨 일치율**이다.
현재 앱은 확인 질문과 주제 진행 기억을 추가로 사용하므로 일부 불일치는 그 차이를 포함한다.

## 남은 품질 문제

수정 후 불일치 63턴은 관점·상대 선택 29턴, 상성 갈래 대신 다른 답변이나 확인 질문
15턴, 다른 갈래의 질문 11턴, 주제 8턴이다. 단순한 파일·UI 회귀 검사 통과를
상담 정확도 100%로 해석하면 안 된다.

긴 구어체 자기 소개, 약칭·생략, 갑작스러운 주제 전환에서 관점과 대상을 틀리는
사례가 남는다. 스킬 이름만으로 이미 사용한 상태를 말하는 영어 후속 질문도
그 상태를 충분히 반영하지 못할 수 있다. 한국어 원문의 문법과 라인전 질문에 대한
정글 운용 조언 같은 내용 적합성은 번역 승인만으로 해결되지 않는다.
전체 게임 조언의 사실성과 일반 대화 능력을 이번 점검으로 인증하지 않았다.

질문·예상 라벨·실제 답변은 [수정 전](baseline.json), [수정 후](results.json),
[대표 답변](representative-replies.json)에 저장했다. 개인 실행 환경, 모델 세션 정보와
대용량 실행 로그는 포함하지 않는다. 회귀는 다음 명령으로 다시 확인할 수 있다.

```sh
node --import tsx --test tests/unit/advisor-translation-quality.test.ts tests/data/advisor-translation-quality.test.ts
npm run build
npx playwright test e2e/advisor-translations.spec.ts
```
