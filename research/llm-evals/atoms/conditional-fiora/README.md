# 피오라 W 조건부 판단 단위 실험 — 2026-10-01

## 목표와 구성

기존 문장 원자를 `필요한 상태 → 이유 → 행동` 단위로 다시 쪼갰다. 잭스·아트록스로 피오라를
상대할 때만 6개 단위를 만든다. `atoms.seed.json`의 이유와 행동은 현재 답 은행 또는 플레이북의
**정확한 인용문**이다. `build-conditional.ts`가 실제 상성의 플레이북 적용 조건과 인용 위치를
확인하고 전체 출처의 SHA-256 앞 16자리, 자료 패치, 노트 검증 패치를 `atoms.lock.json`에 기록한다.
선택할 때도 현재 출처의 지문을 다시 검사한다. 출처가 달라지면 이번 턴의 기존 답변을 사용한다.

W의 상태는 앱의 `planDialogue`가 기억한 조건을 쓴다. 내 E·Q가 빠졌다면 필요한 콤보를 제외하고
남은 행동 중 맞는 것을 고른다. 아트록스가 W 부재를 이용해 들어갈 때는 피오라 Q 직후라는
선행 조건도 함께 붙인다. 아이템·일반 라인전·다른 상성에는 실험 답변을 적용하지 않는다.
모델 추론·문장 생성은 사용하지 않았고, 현재 서비스의 답변 경로에도 연결하지 않았다.

## 재생 결과

| 세트 | 상성 턴 | 단위 사용 | 이번 턴의 기존 답변 사용 | 기존 답의 상태 충돌 표현 | 실험 답의 상태 충돌 표현 |
|---|---:|---:|---:|---:|---:|
| 탐색 7대화 | 17 | 14 | 3 | 7 | 0 |
| 별도 5대화, 수정 전 | 7 | 4 | 3 | 3 | 0 |
| 별도 5대화, 경로·상태 추출 수정 후 | 10 | 5 | 5 | 5 | 2 |
| 별도 5대화, 판단 단위까지 보강 후 | 10 | 8 | 2 | 5 | 0 |

숫자는 `replay-conditional.ts`의 **명시적인 표현 검사**다. 이미 W가 빠졌는데 다시 빼거나
살아 있는 W를 경계하는 문장, 내 E가 없는데 쓰라는 문장, Q가 빠졌는데 즉시 Q를 경계하는 문장,
아트록스 진입의 Q 선행 조건이 누락된 문장을 세었다. 전체 사실성이나 사람이 느끼는 답변 품질의
점수는 아니다. 보류 세트의 첫 실행 결과를 보고 경로와 상태 추출을 고쳤으므로 최종 수치를
맹검 성능으로 해석해서는 안 된다. 결과 전문은 `results.json`, `holdout-results.json`(첫 실행),
`holdout-after-fixes.json`(대화 수정 직후), `holdout-final.json`에 있다.

예를 들어 잭스에게 “상대 W가 빠졌으면 어떻게 교환해?”라고 하면 현재 답변은 W가 남아 있을 때
주의하라는 문장을 함께 보여준다. 조건부 단위는 W가 빠진 뒤 E·Q로 교환하는 행동을 고른다.
아트록스가 W를 빼는 질문에서는 Q 1·2타로 유도한다는 전용 노트를 선택한다. 내 Q가 빠졌거나
다른 챔피언이면 해당 전용 행동을 제외한다.

## 한계와 다음 적용 기준

- 플레이북 노트의 `verifiedPatch`는 26.17이고 현재 답 은행은 26.19다. 지문은 출처의
  **변경 여부**를 검사할 뿐, 26.19 게임에서 그 판단이 옳다는 독립 검증은 아니다.
- 짧은 인용만 조합한 한국어 질문 실험이다. 다른 언어, 다른 챔피언, 0.8B 문장 생성은 평가하지 않았다.
- 상태 충돌 검사에 안 걸리는 부정확함과 답변의 자연스러움은 별도의 사람 평가가 필요하다.
- 적합한 단위가 없으면 현재 답변으로 돌아온다. 모든 상성의 기존 은행 문장이 상태 조건에 맞는다고
  보장하지 않으므로, 서비스 적용 전에 이 복귀 경로까지 평가해야 한다.

서비스 적용은 같은 구조로 만든 독립 질문에서 직접성·행동의 구체성·출처 조건을 함께 평가한 뒤
좋아진 상성만 선택하는 것이 적절하다. 그 전까지 본 실험은 연구 경로에서만 실행한다.
