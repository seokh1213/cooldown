# 노트 원자 조립 실험 (2026-09-24)

평가 30문항(`scripts/llm/eval-connector.ts evalItems`), 맹검 1~5점. 채점자는 Claude CLI 와 Codex 두 명.
같은 판도 회차마다 ±0.25 흔들리므로(조립판 3.13~3.43 · Codex 3.73~4.10) 한 회 평균 차가 아니라
여러 회·두 채점자의 승패로 판단한다.

## E1 채점 신뢰도

| | Claude | Codex |
|---|---|---|
| 조립판(assembly) | 3.37 | 4.10 |
| 원자 판(atoms) | 3.27 | 4.03 |

두 채점자의 승패 일치 22/30. Codex 가 후하지만 순서는 같다. 원자 판 ≈ 조립판(6회 합산 63승 68패).

## E2 조립 변형 (`atoms-v:<변형>`)

| 변형 | Claude | Codex | 비고 |
|---|---|---|---|
| short — 칸마다 한 줄 덜 | 2.70 | 3.30 | 조립판에 2승 20패 |
| long — 칸마다 한 줄 더 | 2.73 | 3.33 | 길이만 늘리면 나빠진다 |
| notrait — 특징 줄 빼기 | 3.63 | 3.97 | 차이 작음 |
| fullnote — 첫 칸 첫 원자를 노트 전문으로 | 3.63~3.93 | 3.80~4.03 | |
| **fullall — 첫 칸 원자 모두를 노트 전문으로** | **3.70~3.93** | **3.73~3.97** | |

줄을 더하면 나빠지고 노트 전문으로 펼치면 좋아진다 — 길이가 아니라 노트 한 편의 이어짐이 점수를 만든다.

fullall 은 아이템 질문에서만 졌다(평균 −0.81, 4승 12패). 펼친 전문 안에 같은 칸의 도출 문장이
또 들어 있어 "모렐로노미콘 …" 이 두 번 실렸다. `atomSections` 가 다른 문장에 통째로 든 문장을
빼게 고친 뒤(E5):

| | Claude | Codex |
|---|---|---|
| assembly | 3.13 | 3.73 |
| atoms | 3.03 | 3.87 |
| **atoms-v:fullall** | **3.87** | **4.20** |

fullall 대 조립판 38승 12패 10무. 아이템 질문도 +0.13 으로 돌아섰다.

## E3 영어·중국어 — 번역 원자

노트가 한국어뿐이라 두 언어 답은 카드 도출 문장만으로 지어진다(current). `translate-atoms.ts` 로
원자를 옮기고(Codex, 스킬 이름 대응표, 코드 대조) 같은 칸 규칙으로 조립했다. notes 는 fullall 의
두 언어판 — 노트 번역이 없으니 같은 노트의 번역 원자를 이어 전문을 대신한다.

| | current | atoms | notes |
|---|---|---|---|
| en · Claude | 1.79 | 2.90 | **3.41** |
| en · Codex | 2.17 | 3.07 | **3.10** |
| zh · Claude | 1.97 | 2.86 | **3.62** |
| zh · Codex | 2.03 | 2.90 | **3.00** |

번역 통과: 원문이 부른 스킬만 대조하게 고친 뒤 en 98% · zh 99%(평가 22명 원자 1,628건).
처음에는 원문이 부르지 않은 패시브(피오라 급소)까지 요구해 11% 가 떨어졌다.

## E4 kev 관련성 거르개 — 상한 먼저

헤드를 학습하기 전에 교사(Codex) 라벨 그대로 거른 판(oracle)을 채점했다.

| | Claude | Codex |
|---|---|---|
| atoms → +oracle | 3.07 → 3.00 | 3.57 → 3.70 |
| fullall → +oracle | 3.70 → 3.77 | 3.73 → 4.10 |

Codex 라벨로 거른 판을 Codex 만 높게 본다(자기 선호). Claude 기준 상한이 거의 없어 헤드 학습은 하지 않는다.

## 결론

- 한국어: 원자 조립 + 첫 칸 노트 전문(fullall) + 포함 문장 제거가 지금 조립판보다 낫다(두 채점자 모두).
- 영어·중국어: 번역 원자를 싣는 것만으로 1.8~2.2 → 3.0~3.6. 가장 큰 개선 폭.
- kev 는 선별·거르기 모두 채점 잣대와 어긋났다. 규칙 조립이 낫다.

`judge-e5-*`(포함 문장 제거 후) · `lang-*`, `lang3-*`(E3).
