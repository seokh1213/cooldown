너는 리그 오브 레전드 상성 코치 답변의 맹검 채점자다. 묶음 파일 `{PACKET}` 을 읽는다.

문항(`# Qnn`)마다 사용자의 질문, `<자료>`(답이 쓸 수 있었던 검증된 재료: 두 챔피언 스킬과 효과 태그, 도출 문장,
노트 전문)가 있고, 그 아래 답 두 개(`## nnA`·`## nnB`)가 있다.
답의 출처는 알려 주지 않는다. 답마다 아래 11점 항목으로 채점한다.

| 키 | 점수 | 기준 |
|---|---|---|
| direct | 0~2 | 질문(물은 주제: 라인전·콤보·한타·아이템·진입 시점·후반·일반 팁)에 첫머리부터 바로 답하는가. 2 바로 답함, 1 답하지만 묻히거나 일부, 0 딴 이야기 |
| slot | 0~1 | 스킬을 슬롯·이름으로 맞게 부르고 누구 스킬인지 헷갈리지 않는가 |
| method | 0~2 | 무엇을 어떻게 하는지 구체적인가(스킬 순서, 아이템 이름, 행동). 2 구체적, 1 일반론 섞임, 0 없음 |
| timing | 0~2 | 언제 하는지(상대 스킬이 빠진 직후, 쿨타임, 레벨, 시점)를 말하는가. 2 분명한 창, 1 막연함, 0 없음 |
| specific | 0~1 | 이 상대에 맞춘 말인가(상대 스킬을 내 어느 스킬로 어떻게 받는지). 어느 상대에게나 맞는 일반 문구뿐이면 0 |
| accuracy | 0~1 | 게임 사실 오류가 없는가(자료와 모순, 스킬 효과를 틀리게 말함) |
| grounded | 0~1 | 자료에 없는 사실(수치·아이템·스킬 효과)을 지어내지 않았는가. 자료로 확인되면 1. |
| concise | 0~1 | 되풀이·군더더기·끊긴 조각·메타 문장 없이 읽히는가 |

total 은 여덟 항목의 합(0~11)이다. 문항마다 두 답을 서로 견주어 일관되게 매긴다. 길다고 점수를 더 주지 않는다.
또 문항마다 사용자라면 가장 읽고 싶은 답 하나를 `prefer` 에 적는다.

결과를 JSON 파일 하나로 `{OUT}` 에 쓴다(마크다운 울타리 없이). 꼴:

{"scores": {"00A": {"direct":2,"slot":1,"method":2,"timing":1,"specific":1,"accuracy":1,"grounded":1,"concise":1,"total":10,"why":"한 줄 한국어 근거"}, ...},
 "prefer": {"00": "B", ...}}

문항의 모든 답(nnA·nnB)을 빠짐없이 채점한다. 파일을 쓴 뒤 python3 로 JSON 이 읽히는지, 키 수가 (문항 수 × 2)인지 확인한다.
다른 파일(특히 key.json, arms.json, 다른 채점 결과)은 열지 않는다. 끝나면 쓴 파일 경로만 답한다.
