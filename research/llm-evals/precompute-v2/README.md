## 2. 고친 것

- **v2 프롬프트** (`precompute-matchups.ts` `V2_RULES`): 첫 문장은 결론이고 앞말 없이 선다 / build 는 자료의 아이템 이름을 쓴다 /
  combo 는 순서를 → 로 / fight·escape 는 '언제' 를 한 번은 분명히 / laning·phase 는 2문장 이상 / 겹치는 노트는 한 번만. v1 은 글자 그대로 둔다.
- **수치 떼기** (`stripNumericAsides`): 코드 규칙(groundCommentary)은 숫자가 든 문장을 통째로 버린다. v2 가 시점을 쓰라고 하자
  "E 회전 베기(1레벨 12초)" 처럼 괄호 수치를 붙였고, 그 칸의 결론 문장이 버려져 "이것 하나뿐이므로 …" 조각이 남았다.
  검사 전에 괄호 속 수치만 뗀다(괄호 밖 수치는 그대로 규칙이 가린다). 버린 문장 v2 389 → 327, v1 299 → 257.
- **끊긴 첫머리** (`precomputed.ts` `leadClean`): "이후·그때·이 틈에·그 사이" 등도 뗀다. 앱 표시 단계라 은행을 다시 쓰지 않아도 된다.
