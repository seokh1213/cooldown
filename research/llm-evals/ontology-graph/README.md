# 노트를 온톨로지 그래프로 — 상성 재료 측정 (2026-09-26, 패치 26.19)

지금 상성 재료는 조건(`when`)이 맞는 노트를 통째로 나열하고, 상대와 맞물리는 말은 정규식 고리(이동기·군중 제어)만 잇는다.
노트를 사실 원자(`knowledge/atoms`)로 쪼개 그래프에 싣고 관계를 따라 고르면 나아지는지 쟀다.

  같은 포지션 7,416쌍 중 3,935쌍(53%)에 연결이 생기고 쌍당 0.86건. 공리로 문장을 짓지 않는다.

## 결론

- **미리 쓴 답(생성) 재료를 그래프로 바꿔도 나아지지 않는다.** 큰 모델은 노트 나열에서도 스스로 맞물림을 잇는다(pre 의 특화가 이미 1.00).
  원자로 쪼개면 조건·주어가 떨어져 오히려 틀린 옮김이 생긴다. 지금 재료를 유지한다.
- **노트 조립(모델 없음·미리 쓴 답이 없는 쌍)에는 작은 이득 가능성.** +0.17(구간 하한 0.00), 25무. kev 고르기(C, +0.15)와 같은 크기다.
  이득은 간결·방법에서 났고, 교차 연결 문장이 실린 문항은 40 중 4. 채택하려면 문항을 늘려 다시 재야 한다.
- 순서를 바꾸는 쪽(그래프·kev)은 조립의 천장(간결 0.2~0.3)을 못 넘는다. 조립과 생성의 차(+1.3)는 여전히 미리 쓴 답에서만 난다.
