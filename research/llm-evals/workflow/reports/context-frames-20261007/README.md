## 선택

`guarded` 정책으로 서로 다른 작업 참조를 최대 12개 보관한다. 같은 작업은 갱신하고 모호한 복귀는 대상 확인을 거친다. 기본값은 `src/lib/advisor/contextFrameTypes.ts` 한 곳에서 관리한다. [실행·되돌리기 절차](../../CONTEXT_FRAMES.md)를 사용한다.

변경 전 대화 처리 1조합과 LIFO·종류별·보호 정책·학습형 네 정책에 2·4·6·8·12개를 적용한 20조합, 총 21조합을 비교했다. 품질이 같으면 더 작은 목록을 선택한다는 기준이었으나 12개가 가장 많은 복귀 요청을 해결했다. 시험 범위보다 큰 개수의 최적성은 주장하지 않는다.

## 기존 회귀와 학습형 제외

[기존 대화 비교](final-regression-offline.json)에서 자동 채점 2,222턴은 변경 전·보호 정책 12개 모두 통과했다. 보호 답변 변경과 회귀는 0건이다. 기대값 없는 10턴은 성공 수에서 제외했다. 단위·데이터 검사 1,345개, 문맥 단위 검사 17개, 타입 검사와 경고 0개 린트가 통과했다.

[전체 회귀 워크플로우](workflow-regression.json)는 5,775측정 중 성공 5,724, 실패 31, 수동 20이다. 31건은 기존 요청 분류기 단독 시험이며 분류 코드·특징·웨이트의 기준 master 대비 동일 SHA-256을 기록했다. 문맥 변경이 이 오류를 해결했다고 보고하지 않는다. 공통 실행기의 문맥 비교·입력 불변·분할·완료 검사는 모두 통과했다. 수동 의미 검토와 일치하는 전체 baseline이 있어야 하는 기존 승격 조건도 유지했다.

학습형은 새 문맥 247/250, 기존 자동 대화 2,220/2,222로 기본 적용에서 제외했다. 회귀 `74ffb1087580d1494eab:3`은 두 상성의 동시 복귀를 확인 질문으로 막았고, `3a711e9c46aee5e8aaaf:3`은 기본 능력치 요청에 이전 레벨을 승계했다. 기본 정책은 이 선택기 파일을 다운로드하지 않는다.

[학습 기록](training.json)의 별도 로지스틱 선택기는 Qwen·Kev hidden-state 헤드를 다시 학습한 결과가 아니다. 107개 학습 템플릿에서 3,852세션·24,182후보 쌍, 선택용 21개 템플릿에서 756세션·4,746쌍을 만들었다. 선택용 macro exact accuracy는 0.623015873이다. 문장 확장 세션을 독립 실사용 표본으로 세지 않는다. 숫자 마스킹·정규화 후 평가 질문과 학습 질문의 중복은 0건, Python/TypeScript 41행의 최대 확률 오차는 3.3306690738754696e-16이다.

## 출처와 한계
