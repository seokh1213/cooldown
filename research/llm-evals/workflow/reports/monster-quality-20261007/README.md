# 몬스터 상세 자료와 기존 품질 오류 검수

26.19 기준 몬스터 상세 자료와 검색·대화 처리를 수정했다. 기존 실패 1,095건은 현재 평가에서 31건으로 줄었다. 남은 31건은 변경하지 않은 경량 요청 분류기의 단독 평가 오류다. 수동 의미 검토 20건도 자동 통과로 바꾸지 않았다.

## 승인 자료와 버전

`knowledge/monster-notes.json`은 몬스터 14종, 능력치 84개, 스킬 규칙 44개, 버프 사실 13개를 담는다. 각 사실은 출처 ID, 승인 원천 해시·위키 revision, 적용 조건, 검수 상태, 변경 패치, 검수 완료 패치와 활성 상태를 가진다. 확인하지 못한 마지막 변경 패치는 `null`이다. 원천 변경 감지는 검수 완료 패치를 자동으로 올리지 않는다.

공식 PC 패치노트 26.1부터 26.19까지, 현재 위키와 16.19 CommunityDragon을 대조했다. 기본 레코드와 실제 생성 레벨의 값을 구분한다. 바론의 기본 공격력 레코드 175는 실제 11레벨 공격력 350.5와 다르다. 대지 드래곤 체력에는 공식 26.1의 기본값 4,200과 성장치 430을 사용한다. 몬스터 레벨을 공격하는 챔피언 레벨이나 경과 시간으로 바꿔 계산하지 않는다.

충돌한 사실 8개는 현재값으로 확정하지 않았다. 바론 사거리·오라, 유충 공격 속도, 전령 공격력, 화학공학 드래곤 공격력, 장로 드래곤 공격력·체력 재생, 레드 버프 근접 둔화율이다. 해당 사실의 `verifiedThroughPatch`는 `null`이며 답변에도 충돌 또는 미확인을 표시한다. 공식 26.1의 영역형 바론 100% AD와 천리안형 바론 140% AD는 이전 위키 수치와 구분했다. 수집 후보는 승인된 게임 사실을 덮어쓰지 않는다.

챔피언·아이템을 포함한 기존 노트의 버전 구조는 유지한다. 기존 26.18 표시는 26.19로 일괄 변경하지 않는다. 아타칸, 힘의 위업과 과거 제거된 소환사 주문은 제거 패치·적용 범위를 관리하며 채팅에서도 제거 상태를 우선 제공한다. 오래된 주문 원문을 현행 효과로 답하지 않는다.

## 원천 감시

GitHub Actions의 `Watch Game Knowledge`는 매일 UTC 00:37에 실행한다. 정적 데이터가 실제 생성된 경우에도 후속 실행한다. 공식 패치노트 URL은 Riot PC 사이트맵에서 발견하며 고정 패치와 최근 패치를 함께 수집한다. Wiki API는 원문·게임 규칙 영역·revision을 보존하고, CommunityDragon은 버전이 고정된 일반 CharacterRecord를 사용한다.

원천 등록은 89개다. 최신 로컬 수집은 87개 성공, 2개 실패였다. 화학공학·화염 드래곤 CommunityDragon 원천의 HTTP 522 오류로 완전 수집을 승인하지 않았으며 기존 감시 기준을 유지했다. 자세한 결과는 `source-check-local.json`에 남겼다. 실패를 변경 없음으로 처리하거나 승인 해시를 초기화하지 않았다.

감시는 승인된 몬스터 사실과 일반 메커니즘·제거 상태 노트의 출처를 연결한다. 승인 해시 불일치와 원천 변경을 별도로 기록하고 영향 받은 노트를 검수 대상으로 남긴다. 수치·활성 상태·검수 패치의 자동 승인은 수행하지 않는다.

현재 위키 주소로 옮긴 49개 URL은 페이지 존재와 revision을 검수해 `knowledge/source-url-migrations.json`에 기록했다. 총 78곳의 주소를 바꿨다. 주소 변경만으로 본문의 수치를 새로 검증했다고 표시하지 않는다.

## 같은 조건의 품질 비교

기존 기준은 5,775개 측정 중 통과 4,660개, 실패 1,095개, 수동 판정 20개였다. 질문과 초기 문맥은 유지했다. 실제 답변 대신 보조 라우터를 채점하던 검사는 실제 답변을 검사하도록 수정했고, 올바른 부정 표현을 오답으로 판정하던 검사를 수정했다.

60개 기대값에는 검수 계약을 추가했다. 이전 기대값, 질문·출처, 변경 이유, 26.19 검수 패치와 근거 파일을 함께 남겼다. 현재 공식 정보와 다른 과거 분류를 정답으로 강제하지 않고, 이름 없는 아이템·광역 효과·구매자 선택에는 필요한 정보를 확인하도록 한다. 사용할 수 없는 스킬을 추천하지 않으며, 직접 대응 근거가 없으면 미확인을 명시한다.

점수 상승 전체를 코드 개선으로 세지 않는다. `fb101f27b84256621ad07d85b9d4dba49bf4b7a8`의 앱 코드에 같은 최신 게임 JSON, 같은 검수 계약과 같은 채점기를 적용한 별도 대조군을 실측했다. 대조군은 통과 4,955개, 실패 800개, 수동 20개다. 수정 앱은 통과 5,724개, 실패 31개, 수동 20개다. 같은 조건에서 코드 변경으로 개선된 측정은 769개이며 새 회귀는 0개다. 보존 대상으로 지정된 기존 답변 8개도 유지했다.

대조군의 모든 답변 측정은 완결됐고 원천·데이터 변경 없음 검사도 통과했다. 이전 테스트가 변경 전 채점 API와 과거 승인 데이터를 사용하는 탓에 대조군의 단위·타입·메커니즘 배포 검사는 실패했다. 이를 통과로 기록하지 않았으며 대조군을 배포 승인 기준으로 사용하지 않는다. 완결된 수정 앱의 실제 결과를 검수 후 CI 기준으로 저장한다.

`baseline-history.json`은 이전 기준의 Git 커밋·파일 경로·SHA-256과 대조군의 해시·검사 결과를 기록한다. 이전 기준 원문은 해당 Git 객체에서 그대로 복원할 수 있다. 완전한 대조군 측정은 `matched-control.json.gz`, 입력 해시는 `matched-control-provenance.json`에 보존한다. 기준 자료·질문·채점기가 다르면 비교를 거부하는 검사도 유지한다.

## 수정 범위와 남은 평가

수정한 경로는 단일 능력치·전체 스킬 범위 구분, 아이템과 챔피언 별명 충돌, 룬 기본 툴팁 검색, 상성·콤보 후속 질문의 대상과 관점, 사용 불가 스킬·보호막·타격 횟수 조건, 저장 후 복원한 대화 기억이다. 데스크톱 WebGPU 확인이 늦게 끝날 때 입력창이 모델 안내로 교체되는 문제도 수정하고 지연된 확인을 재현하는 브라우저 검사를 추가했다.

분류기 재학습과 독립 학습 문장 추가·하이퍼파라미터·앙상블 후보들은 기존 정답에 새 회귀를 만들어 반영하지 않았다. 개발 표본 73/73을 맞힌 후보도 별도 표본에서 새 회귀 7개가 발생했다. 평가 질문을 학습 자료에 복사하지 않았으며 배포 분류기와 가중치는 변경하지 않았다. 남은 오류의 질문·기대값·실측은 `remaining-classifier-errors.json`에 보존한다.

현재 전체 평가의 자동 대화 계약은 통과했지만 경량 분류기 31건과 수동 의미 검토 20건이 남았다. 0.8B 생성 모델 전체 평가를 이번 검증으로 수행했다고 주장하지 않는다. 원천 간 충돌 8개와 수집 실패 2개 역시 분류기 오류와 별도로 관리한다.

## 검증과 배포 확인

단위·데이터 검사 1,316개, 타입·린트, 승인된 챔피언 메커니즘 회귀와 지식 자료 검증을 통과했다. 전체 브라우저 실행은 192개 중 191개를 통과했다. 화면 폭 전환 직후 정리 작업 전에 검사하던 나머지 1개는 대화상자 종료와 inert 정리를 기다리도록 고친 뒤 3회 통과했다. 회귀 실행기는 전체 5,775개를 측정하고 기준 비교·입력 해시 불변·누락 여부를 확인한다. 실제 배포 완료는 GitHub Actions의 배포 실행과 운영 `release.json`의 커밋·앱·데이터 해시를 대조해서 확인한다. 이 보고서의 로컬 검사 결과가 운영 배포 확인을 대신하지 않는다.
