# 질문에 맞춘 규칙 답변

## 인수 조건

1. “점화 틱 간격은?”에는 약 1초 간격·총 5틱의 결론을 답하고, 다른 8개 규칙은 접힌 자료 카드에서 열 수 있다.
2. 틱당 피해를 물으면 레벨에 따라 달라지는 고정 피해라는 조건을 먼저 보인다. 룬 발동의 첫 틱 설명을 피해 간격으로 오인하지 않는다.
3. 정화·점화 상호작용은 지속 피해·시야 노출 제거와 회복 감소 잔존을 함께 설명한다. 별도 게임 원리 답변도 같은 조건을 유지한다.
4. 다른 개체·세 언어에도 같은 선택 방식을 적용한다. 간격·횟수·답문을 특정 개체 이름으로 코드에 넣지 않는다.
5. 선택한 원문 문장의 조건·예외를 보존하고, 복합 질문의 서로 다른 측면을 단일 검색 점수 때문에 버리지 않는다.
6. 전체 효과를 물으면 개요를 임의의 예외 한 줄로 줄이지 않는다. 기존 개체 간 상호작용·쿨타임·삭제 자료 경고를 보존한다.
7. 수치 설명에는 예/아니오 배지를 붙이지 않는다. 질문의 초점과 선택한 문장을 저장·복원한다.

## 원인과 변경

규칙 답변 생성기는 질문 문자열을 받지 않았다. 다른 개체 이름을 언급한 문장이나 쿨타임을 고르지 못하면 원문 전부를 노출했다. `ruleFocus.ts`가 질문의 초점에 맞는 검수 문장을 선택하고 기존 카드의 접기 동작을 사용하도록 바꿨다.

틱 간격·횟수는 수량이 적힌 틱 문장으로 찾는다. 다른 주제는 피해 증폭·은신·피해 종류·스킬 효과를 명확히 물었을 때만 세 언어 주제어로 근거 문장을 선택한다. 서로 다른 질문 측면을 다루는 문장은 모두 남긴다. “어떤 룬을 들어?”나 “어떻게 발동해?” 같은 넓은 질문을 흔한 서술어 하나로 예외 규칙에 연결하지 않는다. 문장을 생성하거나 수치를 계산해 보충하지 않는다. 임의의 테스트 주문에 2초·7틱을 넣은 시험으로 점화 전용 숫자·이름에 의존하지 않음을 확인한다.

원문 문장의 주어가 “이 효과”처럼 생략됐으면 복사 가능한 답문에 개체 이름을 붙인다. 앱과 구 평가 하네스가 이 조립 함수를 함께 사용한다.

실제 브라우저에서 정화 질문을 시험하던 중 별도 `cleanse-ignite` 게임 원리 자료가 회복 감소 잔존을 생략하는 것을 확인했다. 사용자에게 제시된 점화 규칙 원문·기존 번역과 같은 조건으로 한국어·영어·중국어 자료를 맞췄다. 위키 본문은 이번 확인에서 robots 제한으로 재조회하지 못했으며, 새 수치나 별도의 게임 판정을 추가하지 않았다.

## 화면 검증 범위

기존 롤 지식 도우미의 자료 카드 체계를 따른다. 채택된 M6-A의 근거 문장 우선·추가 자료 접기를 사용하며, 색상·서체·레이아웃·장식은 새로 만들지 않는다. ENERGY/RHYTHM/MOTION은 기존 정보 도구의 1/1/1을 유지한다. 핵심 결론이 시선의 중심이고 나머지 규칙은 필요할 때 펼친다.

- R-03 PASS: 390px·1280px 브라우저 시험에서 가로 넘침이 없고 결론을 읽을 수 있다.
- R-09 PASS: 틱 수치 설명에 의미가 맞지 않는 예/아니오 배지가 표시되지 않는다.
- R-26 PASS: 추가 규칙을 펼쳐 은신 설명을 읽고 다시 접을 수 있다.
- R-35 PASS: 빌드한 앱에서 질문 제출·규칙 접기·새로고침 뒤 대화 복원을 실제 실행했다.
- C-3 PASS: 질문에 직접 답하는 문장은 앞에 두고, 다른 규칙 8개는 접근 가능한 추가 자료로 유지한다.
- C-5 PASS: 선택한 문장과 숫자는 기존 검수 자료에서 가져온다. 영상의 원시 관측·미확인 서버 타이머는 제품 설명에 추가하지 않는다.

## 검증 기록

관련 단위·데이터·저장 복원 시험 61/61건이 통과했다. 최종 전체 회귀·푸시·배포 결과와 변경 응답은 같은 폴더의 검증 기록에 보존한다.

최종 코드의 전체 회귀는 5,893건, 성공 5,796건·기존 실패 77건·수동 검토 20건이며 새 실패는 0건이다. 전체 인프라 12/12, unsafeNumeric 0건을 확인했다. 모든 행의 통과 여부와 검사 항목은 이전 기준과 같고 질문·채점기 해시도 유지했다. 모델의 품질 승인이나 기존 실패 해결을 뜻하지 않는다.

[변경 응답 검토](comparison.json)의 30건은 모두 검토했다. 26건은 복사한 쿨타임 답문의 대상 이름만 추가했고, 4건은 정화 답변에 제거되는 효과와 남는 회복 감소를 구체화했다. 그 외 5,863건의 응답 문자열은 동일하다. 자료 변경 파일은 원본 `mechanics-notes.json`과 배포 `advisor-knowledge.json`뿐이다. 실제 완결된 측정 파일로 baseline을 갱신했으며 비교 조건·질문·채점기를 완화하지 않았다.

일반 낱말로 문장을 좁힌 초기 시험에서는 “proc grasp”, “점화랑 순간이동 중에 뭐 들어?” 같은 넓은 질문을 예외 규칙에 연결하는 문제가 확인되어 채택하지 않았다. 명확한 주제만 선택하도록 제한한 뒤 영향받은 31개 대화·106건을 재검사해 새 실패 0건을 확인했고, 이어 전체 회귀로 재검증했다.

최종 전체 단위·데이터 회귀 1,013/1,013건, 세 언어 틱·정화·복합 질문 데이터 29/29건, 모바일·데스크톱 브라우저 2/2건이 통과했다. 브라우저 검사는 재시도 0회이며 실제 로컬 Chrome에서도 한 문장 답변·두 측면의 복합 답변·정화 예외를 확인했다. 타입 검사와 lint도 통과했다. [측정 입력](provenance.json)과 [원본 측정 요약](summary.json)을 함께 보존한다.
