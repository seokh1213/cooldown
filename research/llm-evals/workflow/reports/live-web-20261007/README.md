# 실제 웹 챗봇 비교, 2026-10-07

문맥 복귀 개선을 웹 화면에서 확인했다. 다만 이전 버전은 통과하고 현행은 실패하는 아크샨 후속 질문이 발견돼, 답변 품질 전반의 개선이나 회귀 0건을 주장할 수 없다. 이 기록은 자동 검사의 기존 성공을 부정하는 것이 아니라, 그 검사에 없던 대화 순서에서 발견한 추가 증거다.

## 확인한 개선과 보호 동작

럭스 Q 쿨타임을 물은 뒤 아리·가렌·다리우스·오공·이즈리얼·카이사·레오나·애니·베인·제이스·진·나미·블라디미르의 마법 저항력을 물었다. 이어서 “그 스킬 쿨타임은?”에 현행은 럭스 Q 10초로 복귀했다. 이전 코드는 모델 준비 뒤 반복해도 “어느 챔피언의 어떤 스킬을 말하나요?”라고 되물었다. 실제 웹에서 긴 문맥 복귀 개선이 재현됐다.

럭스 Q와 아리 Q를 모두 다룬 뒤 장화로 주제를 바꾸고 “그 스킬은?”이라고 물으면 현행은 두 후보를 제시해 확인했다. “럭스 말한 거야”라고 답하자 럭스 Q 10초를 보여줬다.

별도 새 대화에서 럭스 Q 다음 서로 다른 챔피언 33명의 스탯을 물었다. 마지막 “그 스킬 쿨타임은?”에는 챔피언·항목을 다시 알려 달라고 했다. 용량을 넘긴 대상을 추측해서 다른 챔피언의 Q로 답하지 않았다. 사용한 대화는 `datasets/context-frames/stress-validation.jsonl`의 `spell-return`, `interveningContexts=33`이다.

## 새로 발견한 회귀: 취소 조건에서 3회 적중으로 전환

새 대화에서 다음 순서를 그대로 입력한다.

1. 아크샨 평타 한 방 치고 두 번째 안 쏘면?
2. 그럼 두 발 전부 쏠게. 이속 생겨?
3. 그럼 평타 세대 맞추면?

1번은 취소 시 이동 속도, 2번은 추가 공격을 발사했으므로 취소 조건에 해당하지 않는다는 설명이 맞다. 3번은 승인된 아크샨 P 규칙에 따라 3회 적중 마법 피해와 챔피언 대상 보호막으로 전환해야 한다.

현행은 3번에서도 “추가 공격까지 발사하면 취소 조건에 해당하지 않습니다”를 반복했다. 새 대화에서 두 번 재현했다. 이전 코드는 같은 3번에 “세 번째 적중마다 추가 마법 피해”, “대상이 챔피언일 때 보호막”을 답했다. **기존 대비 회귀 1종**이다. 일반 패시브 질문 자체가 항상 틀린다는 뜻은 아니다.

관련 소스는 `src/lib/advisor/mechanics/retrieval.ts`의 `selectRules`다. 현행은 이동 주제에서 hit-count 규칙을 고를 때 기억된 `followupStatus`도 검사한다. 이 보고에서는 구현을 수정하지 않았다. 수정 시 새 적중 질문과 이전 취소 조건의 적용 범위를 분리하고, 취소 질문의 기존 보호 동작도 함께 다시 검사해야 한다.

## 이전 버전에도 있는 문제

다음 세 문제는 두 버전에서 동일하게 재현됐다. 새 회귀와 별도로 다룬다.

- 파이크 체력 70짜리 아이템 두 개는 추가 공격력 10을 맞힌다. 이어 “아 아니 추가 체력 42로 정정할게”에는 공격력 3 대신 비스킷 룬 설명을 준다. “아 42로 바꿔줘”라는 기존 시험 표현은 3을 맞힌다. 정정 표현의 일반화가 부족하다.
- “방어력 100 상대로 방관 30%에 고정 방관 10이면 최종 방어력?”에는 최종값 60 대신 일반적인 퍼센트 관통 중첩 설명을 준다. 기존 시험 문장 “방어력이 100인 상대에게 30% 관통이랑 고정 관통 10이 있으면 어떤 순서로 계산해?”는 두 버전 모두 60을 맞힌다.
- 새 대화의 “How should I lane as Ahri against Fizz?”는 라인전을 설명한다. 하지만 아리 6레벨 방어력·마법 저항력을 물은 뒤 같은 영어 질문을 하면 라인전 대신 6레벨 두 챔피언 스탯 비교를 준다. 명시한 새 의도보다 이전 스탯 범위를 이어받는다.

추가 현행 관찰: 페이지에 오공이 선택된 상태에서 “가랜 6렙 방어력이랑 마저 좀”을 입력하니 가렌 확인 없이 오공 수치를 답했다. “가랜” 오타를 해결하지 못한 채 페이지 대상을 쓴 사례다. 이전 버전의 페이지 선택 조건을 맞추지 않아 버전 비교 수치에는 포함하지 않는다.

## 통과한 기존 답변과 사용성 문제

파이크 140→공격력10과 짧은 정정 42→3, 정확한 관통 계산 문장, 이즈리얼 W의 스킬 폭발 시 마나60 추가 환급, 제이스 해머·캐논 Q 쿨타임 분리, 아펠리오스 E가 시전 스킬이 아니라는 설명과 정화 후속 질문은 두 버전 모두 통과했다. 아리 체력·방어력의 18→6레벨 전환도 현행에서 정상 동작했다.

사용성은 더 다듬어야 한다. 아크샨 이동 속도 공식에 `Move Speed`, `bonus Attack Speed`가 그대로 보였다. 자료 패널의 일반 P 요약은 3회 적중을 물리 피해라고 적지만 승인 규칙의 답변은 마법 피해다. 자료 두 출처가 모순되므로 지식 최신화·출처 일치를 별도로 확인해야 한다. 장화 가격 질문의 본문은 이동 속도25만 보여주고, 가격300은 자료 패널에만 있다.

## 응답 시간과 한계

현행 77턴의 UI 완료 시간은 중앙값 858ms, 관측 P95 4,340ms, 최대 4,814ms였다. 반복 스탯 질문과 긴 대화용 질문이 많이 포함된 탐색 결과다. 입력창을 채운 뒤 보내기 클릭 직전부터 새 답변 복사 버튼이 생기고 중단 버튼이 사라질 때까지 잰다. DOM 조회 왕복도 포함한다.

배포 사이트와 localhost의 네트워크·캐시·동시 모델·예열 조건이 다르므로 속도 개선률은 계산하지 않았다. 이 수치를 사용자 전체의 정확도·응답 시간으로 해석하지 않는다. 모델 다운로드 시간은 답변 지연에 포함하지 않는다.
