# 이름 찾기 개선 다섯 가지 (2026-09-27)

브라우저 점검에서 드러난 이름 찾기 약점을 고쳤다. 사전은 평가 문항을 보지 않은 에이전트가 썼고, 평가 문항도 사전을 보지 않은
에이전트가 썼다.

## 1. 아이템 줄임말 (`knowledge/item-aliases.json`, 147개 아이템)

`findItems` 가 공식 이름만 찾았다("쇼진 몇 골드야?" 를 못 찾음). 공식 이름 다음에 줄임말을 낱말 경계로 찾는다.

| 아이템 시험 300(`queries.jsonl`) | 전 | 후 |
|---|---|---|
| 줄임말 질문 120 | 2 | **95** |
| 공식 이름 120 | 120 | 120 |
| 아이템 아닌 질문 60 | 60 | 60 |

다른 세트(약 3,400문항)에서 헛잡음을 보고 막은 것: 룬·소환사 주문을 묻는다고 밝힌 질문은 줄임말로만 걸린 아이템을 보지 않는다
("리안드리 화상으로 영혼 거두는 룬"), 챔피언 별명 안의 줄임말(破败王 의 破败), 바론과 겹치는 내셔·Nashor, 흔한 영단어 void·cleaver.

## 2. 챔피언 별명 (`knowledge/champion-aliases.json`, 한국어 15 · 영어 20 · 중국어 186 추가)

빌드가 설명 본문과 겹치는 별명을 빼서 실제로 놓치던 것(아트·문도·炼金·天使·破败王)이 빠졌다. 사람이 고른 별명은 룬·소환사 주문
**이름**과 겹칠 때만 빼고, 아이템 이름과 겹치는 것은 앱이 아이템 이름을 가린 뒤에 찾는다. 바위게와 겹치는 螃蟹(우르곳)는 뺐다.
한 글자 중국어 이름(烬·彗 …)은 `zh_CN_single` 에만 두고 싣지 않았다("彗星" 속 彗).

## 5. 붙여 쓴 영어·영어 오타

열두 글자 이상 로마자 덩어리 안에서만 영어 이름을 찾는다(Sion ↔ vision). 영어 오타는 여섯 글자 이상 이름만, 아이템 낱말(Greaves)·
흔한 말(rubble·mastery)은 빼고.

route-large 374(정답 챔피언 라벨): 챔피언을 완전히 맞힌 문항 355 → **369**, 새 헛잡음 0(약 3,400문항에서 猫咪 → 유미 한 건, 롤과 무관한 질문).

## 오타 교정의 헛잡음 (덤)

챔피언 이름이 없는 질문 3,174개 중 **271개(8.5%)** 가 오타 후보를 냈다("마법 저항력" → 마스터 이, "스킬 가속" → 가렌, "타워" → 타릭,
"바위게 언제 나와?" → 나르·나미). 후보가 하나면 앱이 스스로 고쳐 다시 물어 엉뚱한 답이 나갔고, 검색 벡터 길도 건너뛰었다.
세 글자 이하는 앞뒤에 이름 자리 문맥(스킬 키·상대법·으로·랑 …)이 있을 때만, 게임 낱말(게임 메타·룬·주문·아이템 이름·줄임말)과
흔한 동사·낱말은 빼고 → **271 → 약 0**. 진짜 오타 16개 중 15개는 그대로 고친다(`tests/data/advisor-names.test.ts`).

## 3·4. 대화 중 (상성 이어 묻기와 새 말 가르기)

- 3: 상성 대화 중 소환사 주문의 쓰임새("점멸 빠지면 물어도 돼?", "instead of flash")는 규칙 카드가 아니라 이어 묻기. 대화 흐름 시험
  (act-test·a-set 의 이름 없는 턴)에서 이름이 든 12문항을 모두 바르게 가른다.
- 4: 게임과 무관한 말("내일 날씨 어때?")은 판정기(kev) 1위가 잡담이고 되묻기·조언 요청 낱말이 없을 때 이어 묻기가 아니다.
  이어 묻기 133 중 0 을 끊고 답 없는 질문 119 중 무관한 9 를 잡는다.

## 하이브리드 검색 메타 가산점 0.05 → 0.1

"바론 몇 분에 나와?" 가 협곡의 전령으로 갔다(전령 본문에 "20분에 그 자리에 내셔 남작이 나옵니다"). 0.1 로 올리면 바론 등장 4문항이
맞고 시험 절반 299·32 → 298·33, 실제에 가까운 질문 26·14 → 26·15 로 한 문항씩 내준다.
