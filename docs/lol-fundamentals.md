# 리그 오브 레전드 기초 — 스탯과 아이템 체계

> 목적: 상성 조언이 "왜 이 아이템인가"를 근거로 말하려면 스탯이 실제로 어떻게 작동하는지와
> 아이템이 어떤 역할군을 위해 설계됐는지를 알아야 한다. 이 문서는 그 기준을 정리한다.
> 출처는 LoL Wiki(wiki.leagueoflegends.com)와 나무위키 아이템 문서, 그리고 우리 정규화 데이터다.

## 1. 저항과 피해 감소

방어력은 물리 피해, 마법 저항력은 마법 피해를 줄인다. 계산은 동일하다.

```
받는 피해 = 원래 피해 × 100 / (100 + 저항)
저항이 음수면 = 원래 피해 × (2 − 100 / (100 − 저항))
```

핵심은 **실효 체력**이다. 저항 1당 해당 피해 유형에 대한 실효 체력이 1% 늘어난다.
체력 1000에 방어력 25면 물리 피해에 대한 실효 체력은 1250이고, 원래 피해 1000은 800으로 들어온다.

여기서 조언에 직결되는 두 가지가 나온다.

- **저항은 체력과 곱으로 작동한다.** 체력만 쌓거나 저항만 쌓는 것보다 함께 쌓는 것이 실효 체력을 크게 만든다.
  탱커 아이템이 체력과 저항을 함께 주는 이유다.
- **저항은 수익이 체감되지 않는다.** 저항 1당 실효 체력 1%는 저항이 높아도 그대로다.
  "마법 저항력을 더 올려도 소용없다"는 말은 틀렸고, 실제로 소용없게 만드는 것은 아래의 관통과 감소다.

## 2. 관통과 감소, 그리고 적용 순서

같은 "저항 무시"처럼 보이지만 성질이 다르다.

| 구분 | 대상 | 효과 범위 |
|---|---|---|
| 감소(shred) | 대상의 저항 자체를 깎는다 | **우리 팀 전체**에게 적용 |
| 관통(penetration) | 계산할 때만 저항을 낮게 본다 | **그 챔피언의 피해**에만 적용 |

적용 순서는 감소가 먼저, 관통이 나중이고 각 단계에서 비율이 고정보다 먼저다.

```
1) 고정 감소  →  2) 비율 감소  →  3) 비율 관통  →  4) 고정 관통(물리 관통력/치사량)
```

- 고정 감소는 저항을 음수까지 내릴 수 있지만 비율 감소는 0 아래로 내리지 못한다.
- 비율 관통과 물리 관통력은 대상 저항이 0 이하면 아무 효과가 없다.
- 물리 관통력(치사량)은 V14.1 이후 레벨에 비례하지 않는다. 표기된 수치만큼 방어력을 무시한다.

**조언에 쓰는 규칙**

- 상대에게 저항 감소 스킬이 있으면 내 저항 아이템의 값이 실제로 떨어진다.
  그래서 럼블 E 전기 작살처럼 마법 저항력을 깎는 스킬은 회피 우선순위가 가장 높다.
- 고정 관통은 저항이 낮은 대상(딜러)에게, 비율 관통은 저항이 높은 대상(탱커)에게 값을 한다.
  그래서 암살자는 물리 관통력을, 지속 피해형은 비율 관통을 든다.

## 3. 고정 피해

고정 피해는 방어력도 마법 저항력도 줄이지 못한다. 대응 수단은 체력, 회복, 거리 유지뿐이다.
피오라 패시브 급소와 R, 가렌 R처럼 고정 피해가 주력인 스킬을 상대로 저항 아이템을 먼저 사는 것은 잘못된 조언이다.

## 4. 스킬 가속

```
쿨타임 감소율 = 가속 / (100 + 가속)
최종 쿨타임 = 기본 쿨타임 × 100 / (100 + 가속)
```

- 가속끼리는 더하기로 쌓인다. 예전 쿨감(곱연산, 40% 상한)과 다르다.
- 감소율은 100%에 닿지 않는다. 가속 상한은 500(감소율 83.3%)이다.
- 스킬 가속과 궁극기 가속은 더해지며 합계에 같은 상한이 걸린다.

**조언에 쓰는 규칙**: 쿨타임이 긴 핵심 스킬을 가진 챔피언은 가속의 체감이 크다.
반대로 쿨타임이 이미 짧은 스킬 위주 챔피언은 가속보다 피해 스탯이 낫다.

## 5. 공격 속도, 치명타

- 추가 공격 속도는 기본 공격 속도에 비율로 더해진다.
- 공격 속도에는 상한이 있고, 상한을 넘긴 초과분은 일부 스킬 계수로만 환산된다.
- **적의 공격 속도 감소(둔화 계열)는 최종 공격 속도에 곱으로 걸린다.** 그래서 평타 의존 챔피언에게
  얼어붙은 심장이나 마법사의 최후 같은 공격 속도 감소가 강하게 작동한다.
- 치명타는 원거리 딜러 아이템군의 축이다. 치명타 확률 아이템은 평타를 여러 번 넣는 챔피언에게만 값을 한다.

## 6. 강인함

- 군중 제어 지속시간을 줄인다. 상한 100%이고, 어떤 경우에도 지속시간이 0.3초 밑으로는 내려가지 않는다.
- **같은 그룹끼리는 곱, 다른 그룹끼리는 합**으로 쌓인다. 헤르메스의 발걸음 30%와 전설: 강인함 20%를
  더해 50%가 되는 것이 아니라 1 − (0.7 × 0.8) = 44%다.
- 이동기가 없는 챔피언은 군중 제어 한 번에 콤보를 통째로 받는다. 그래서 마법 저항력보다 강인함이 먼저인 경우가 있다.

## 7. 아이템 등급

| 등급 | 특징 | 데이터 판정 |
|---|---|---|
| 소모품·장신구 | 물약, 와드 | `Consumable`, `Trinket` 태그 |
| 시작 아이템 | 도란 계열, 정글 아이템, 여신의 눈물 | 이름과 가격, 조합 관계 |
| 기본 | 조합 재료 | 상위 조합만 있고 하위 조합 없음 |

| 전설 | 최종 아이템 | 상위 조합 없음 |
| 장화 | 이동 속도 전용 계열 | `Boots` 태그 |

## 8. 아이템 역할군 — 위키의 상점 분류를 쓴다

게임 상점은 아이템을 **브루저·탱커·메이지·원거리 딜러·암살자·서포터** 탭으로 나눠 보여준다.
라이엇 데이터에는 그 분류가 없다.

- CommunityDragon `v1/items.json` 의 `categories` 는 우리 `tags` 와 같아 스탯 종류만 알려준다.
- 역할군별 상점 탭 에셋을 찾지 못했다(`shop-item-categories.json` 등 404).

**LoL Wiki(Fandom) `Module:ItemData/data` 가 `menu` 필드로 이 분류를 관리한다.**
`npm run llm:fetch-wiki-items` 로 수집해 `item-wiki-meta.json` 에 저장한다(CC BY-SA).

| 필드 | 내용 |
|---|---|
| `menu` | fighter 61, tank 62, mage 75, marksman 63, assassin 54, support 48, movement 23, onhit effects 28, lifesteal vamp 6, armor pen 4, magic pen 1 … |
| `type` | Legendary 115, Epic 46, Basic 15, Starter 18, Boots 12, Consumable 19, Trinket 7, Prismatic 47(아레나) … |
| `itemlimit` | 동시 보유 제한 그룹 (예: Hydra) |
| `nickname` | 별칭 (무한의 대검 = ie) |

숫자 `id` 로 우리 한국어 데이터와 대응된다. 협곡 아이템 254개 중 193개가 매칭되고
2026년 신규 61개는 위키에 아직 없다. **위키 분류가 있으면 그것을 쓰고, 없으면 스탯 조합으로 추정한다.**
추정 규칙은 `scripts/llm/lib/itemArchetype.ts` 에 있다.

상점 탭은 한 아이템이 여러 개에 걸린다(칠흑의 양날 도끼 = fighter + assassin).
그래서 후보 판정은 "제외 역할군이 하나라도 있으면 배제" 가 아니라
"선호 역할군에 하나라도 걸리면 통과" 로 한다. 단 아군 보조 아이템은 예외로 무조건 제외한다.
상점이 기사의 맹세를 탱커 탭에도 올려 두지만 서포터가 아닌 챔피언에게는 값을 하지 못한다.

### 위키가 없을 때의 추정 규칙

| 역할군 | 판정 규칙 |
|---|---|
| 서포터 | 오라 태그, 골드 획득 태그, 아군 대상 문구, 아군 지정 필요 |
| 브루저 | 공격력(스탯 또는 "추가 공격력" 문구) + 생존 스탯(체력·방어력·마법 저항력) |
| 탱커 | 생존 스탯만, 또는 저항과 체력을 함께 주고 치명타가 없음 |
| 메이지 | 주문력 + 마나·마법 관통·스킬 가속 |
| 마법 전사 | 주문력 + 체력 |
| 원거리 딜러 | 치명타, 또는 공격력 + 공격 속도 + 생명력 흡수 |
| 암살자 | 공격력 + 물리 관통, 생존 스탯 없음 |

판정에서 주의한 예외

- 스테락의 도전은 스탯이 체력뿐이지만 효과가 추가 공격력을 준다. 문구를 읽어 브루저로 넣는다.
- 마법사의 최후는 마법 저항력을 주지만 공격 속도 아이템이므로 탱커가 아니라 브루저·원거리 딜러다.
- 기사의 맹세는 방어력과 체력을 주지만 아군 대상 아이템이므로 서포터로만 취급한다.
- 오른 업그레이드 등으로 같은 이름이 두 번 등장하므로 이름 기준으로 중복을 제거한다.

## 9. 챔피언 분류 — 두 외부 출처를 함께 쓴다

챔피언 분류는 추정하지 않는다. 서로 보완하는 두 출처를 수집해 쓴다.

| 출처 | 알려주는 것 | 수집 명령 |
|---|---|---|
| 라이엇 (CommunityDragon) | 역할 태그 순서, 주·부 특성, 피해 유형, 근접·원거리, 플레이스타일 지표 | `npm run llm:fetch-meta` |
| LoL Wiki (Fandom) | **하위 클래스**(저거너트·스커미셔·다이버 …), **포지션**(탑·정글·미드·바텀·서포터) | `npm run llm:fetch-wiki` |

### 9-1. LoL Wiki 하위 클래스 — 실제 빌드가 갈리는 층

Fandom 의 `Module:ChampionData/data` 를 `action=parse` API 로 받아 파싱한다(CC BY-SA).
라이엇 역할 태그는 `Fighter/Tank` 까지만 알려주는데, 위키는 그 안을 다시 나눈다.

| 클래스 | 하위 클래스 | 수집된 수 |
|---|---|---|
| Fighter | Juggernaut, Diver, Skirmisher | 14, 17, 16 |
| Tank | Vanguard, Warden | 15, 7 |
| Slayer | Assassin, Skirmisher | 19 |
| Mage | Burst, Battlemage, Artillery | 18, 11, 7 |
| Marksman | Marksman | 25 |
| Controller | Enchanter, Catcher | 12, 10 |
| — | Specialist(분류 불가) | 14 |

이 층이 필요한 이유는 같은 `Fighter/Tank` 안에서 빌드가 갈리기 때문이다.

- 나서스·다리우스·가렌·세트 = **Juggernaut** → 브루저와 탱커 아이템
- 레넥톤·카밀 = **Diver** → 브루저와 탱커, 물리 관통도 후보
- 피오라·잭스·야스오·그웬 = **Skirmisher** → 브루저와 함께 **치명타 아이템도 후보**
  (야스오가 치명타를 사는 이유가 이 층에서 설명된다)
- 말파이트·오른 = **Vanguard** → 탱커
- 브라움 = **Warden** → 탱커와 아군 보조
- 쓰레쉬 = **Catcher** → 서포터 아이템

포지션도 함께 온다. 탑 46, 미드 43, 정글 41, 서포터 36, 바텀 27이다.
"포지션은 데이터에 없다"는 한계가 이것으로 해소됐다.

170/173 챔피언이 매칭됐고 못 찾은 3종(Locke, Yunara, Zaahen)은 위키에 아직 등재되지 않은 신규 챔피언이다.

### 9-2. 라이엇 데이터 — 피해 유형의 최종 근거

스킬 툴팁으로 피해 유형을 추정하면 틀린다. 나서스가 대표적이다. Q 흡수의 일격은 중첩으로
피해가 커져 데이터에 계수가 없고, E와 R만 주문력 계수를 가져서 "AP 챔피언"으로 읽혔다.
실제 나서스는 브루저 또는 탱커다.

**라이엇이 직접 붙인 분류가 CommunityDragon 에 있다.**
`rcp-be-lol-game-data/global/<locale>/v1/champions/<key>.json` 의 필드다.

| 필드 | 내용 | 나서스 값 |
|---|---|---|
| `roles` | 순서 있는 역할 태그 | `["fighter","tank"]` |
| `championTagInfo` | 주·부 특성 | 내구성 / 하이퍼캐리 |
| `tacticalInfo.damageType` | kPhysical / kMagic / kMixed | **kPhysical** |
| `tacticalInfo.attackType` | melee / ranged | melee |
| `playstyleInfo` | damage·durability·crowdControl·mobility·utility (0~3) | 내구도 **3** |

`npm run llm:fetch-meta` 로 173 챔피언분을 수집해
`public/data/<patch>/llm/champion-riot-meta-<locale>.json` 에 저장한다. 수집 결과 분포는
물리 78 / 마법 87 / 혼합 8, 근접 90 / 원거리 83이고 주 특성은 기동력 22, 폭발적 피해 17,
군중 제어 14, 결투가 13, 기본 공격 12 순이다.

### 9-3. 판정 순서

1. **아이템 풀은 위키 하위 클래스가 정한다.** `SUBCLASS_POOLS` 표를 따른다.
   Specialist(티모·신지드·케일·퀸 등 14종)는 분류 불가이므로 아래의 역할 태그 규칙으로 넘긴다.
2. **AD/AP 는 라이엇 `damageType` 이 결정한다.** 스킬 계수 추정은 이 값이 없을 때만 쓴다.
   방어 기준 스탯 판정과 프롬프트의 자동 결론도 이 값을 우선한다.
3. **근접·원거리는 라이엇 `attackType` 이 결정한다.** 사거리 수치 기준(300)은 예비 수단이다.
4. **내구도 3 또는 주 특성 "내구성" 이면 탱커 아이템을 후보에 더한다.**
5. **역할 태그는 순서가 의미를 가진다.** 첫 번째가 주 역할이다.

`npm run llm:profiles` 로 판정 결과를 확인한다. 주요 챔피언 판정은 다음과 같다.

| 챔피언 | 라이엇 역할 | 피해 | 주 특성 | 내구 | 판정 |
|---|---|---|---|---|---|
| 나서스 | Fighter/Tank | 물리 | 내구성 | 3 | 탱커 → 브루저 |
| 아트록스 | Fighter | 물리 | 지속 피해 | 3 | 탱커 → 브루저 |
| 다리우스 | Fighter/Tank | 물리 | 결투가 | 2 | 브루저 → 탱커 |
| 피오라 | Fighter/Assassin | 물리 | 결투가 | 2 | 브루저 → 탱커 → 암살자 |
| 말파이트 | Tank/Mage | 마법 | 전투 개시 | 3 | 탱커 → 마법 전사 → 메이지 |
| 그웬 | Fighter | 마법 | 지속 피해 | 2 | 마법 전사 → 탱커 → 메이지 |
| 티모 | Marksman/Mage | 마법 | 지속 피해 | 1 | 메이지 → 마법 전사 |
| 케이틀린 | Marksman | 물리 | 기본 공격 | 1 | 원거리 딜러 → 암살자 → 브루저 |
| 제드 | Assassin | 물리 | 폭발적 피해 | 1 | 암살자 → 브루저 |
| 브라움 | Tank/Support | 마법 | 내구성 | 2 | 탱커 → 서포터 |

### 규칙표

ddragon 태그 조합은 26가지이고 가장 많은 것이 `Fighter/Tank`(20종), `Fighter/Assassin`(18종)이다.
순서를 무시하면 오분류가 난다.

- 피오라와 카밀은 `Fighter/Assassin` 이다. 주 역할이 전사이므로 **암살자 아이템이 아니라 브루저 아이템**을 산다.
  부 역할이 암살자이므로 물리 관통 계열(세릴다의 원한 등)만 후보에 남긴다.
- 말파이트와 신지드는 `Tank/Mage` 다. 주 역할이 탱커, 부 역할이 마법사인 AP 탱커다.
- 브라움은 `Tank/Support`, 쓰레쉬는 `Support/Tank` 다. 순서가 다르면 선호가 다르다.
- 티모는 `Marksman/Mage` 이고 계수가 AP 다. 원거리 딜러 태그지만 메이지 아이템을 산다.

여기에 계수 프로필(AD/AP)을 곱해 최종 풀을 정한다. 규칙은 `championBuildProfile` 에 있다.

| 주 역할 | 조건 | 선호 |
|---|---|---|
| Marksman | AD | 원거리 딜러 → 암살자 → 브루저 |
| Marksman | AP | 메이지 → 마법 전사 |
| Marksman | 부 역할 Mage, AD 아님 | 메이지 → 원거리 딜러 → 마법 전사 |
| Support | — | 서포터 → 탱커 → 마법 전사 |
| Mage | 부 역할 Support | 서포터 → 메이지 → 마법 전사 |
| Mage | 그 외 | 메이지 → 마법 전사 |
| Assassin | AD | 암살자 → 브루저 |
| Assassin | AP | 메이지 → 마법 전사 |
| Tank | 부 역할 Support | 탱커 → 서포터 |
| Tank | AP 또는 부 역할 Mage | 탱커 → 마법 전사 → 메이지 |
| Tank | 그 외 | 탱커 → 브루저 |
| Fighter | AP + 물리 피해 스킬 보유 | 마법 전사 → 브루저 → 탱커 → 메이지 |
| Fighter | AP | 마법 전사 → 탱커 → 메이지 |
| Fighter | 부 역할 Assassin | 브루저 → 탱커 → 암살자 |
| Fighter | 그 외 | 브루저 → 탱커 |

선호 목록에 없는 전투 역할군은 자동으로 제외된다. AP 챔피언에게 치명타·물리 관통 아이템이,
AD 챔피언에게 주문력 아이템이 후보로 올라오지 않는다.

여기에 상대 피해 유형으로 방어 스탯을 고르는 규칙을 곱한다.
아트록스가 피오라를 상대하면 브루저·탱커 역할군 중 방어력을 주는 것이 후보가 된다.

`npm run llm:profiles` 로 판정 결과를 확인할 수 있다.

# 부록 — 만드는 쪽 메모

> 여기서부터는 **게임 지식이 아니라 이 자료를 만드는 방법**에 대한 기록이다.
> 도우미의 검색 자료로 쓰지 않는다. 사용자가 "넌 누구야" 라고 물었을 때 자료
> 이름으로 "위키 팁 — 수집했으나 프롬프트에는 넣지 않는다" 가 뜬 적이 있다.
> `parseMechanics` 가 이 표시를 보고 아래를 건너뛴다.

## 10. 남는 한계

- **근접·원거리 전용 제한을 데이터로 알 수 없다.** 히드라 계열이 근접 전용이라는 사실은
  라이엇 문구에도 위키 `menu` 에도 없다. 효과 문구의 "쪼개기", "초승달" 로 근접 성향을 추정한다.
- **메타 적합도는 데이터에 없다.** 어떤 아이템이 현재 강한지는 승률 통계가 필요하다.
  지금은 지식 카드가 그 역할을 하고, 카드가 지목한 아이템을 후보에 고정 포함한다.
- **아이템 효과의 수치 계산은 하지 않는다.** 실효 체력이나 피해량 비교는 시뮬레이션이 필요하고,
  이 프로젝트의 조언은 "왜 이 방향인가"까지만 책임진다.
- **중첩으로 피해가 오르는 스킬은 계수가 데이터에 없다.** 나서스 Q 흡수의 일격이 그렇다.
  라이엇 `damageType`(kPhysical)으로 해결했다. 라이엇 메타를 수집하지 않은 환경에서는
  물리 피해 스킬 보유 여부로 보정한다.
- **패시브가 빌드를 결정하는 경우는 여전히 알 수 없다.** 야스오는 라이엇 분류로도 결투가 성향
  물리 전사이지만 패시브 때문에 치명타 아이템을 산다. 지식 카드가 메운다.
- **포지션(라인)은 데이터에 없다.** 같은 챔피언이 탑과 정글에서 다른 아이템을 쓰는 경우는
  지식 카드의 `lane` 조건으로 구분한다.

## 11. 위키 팁 — 수집했으나 프롬프트에는 넣지 않는다

`npm run llm:fetch-wiki-tips` 로 챔피언별 Strategy 문서에서 팁을 수집한다(CC BY-SA).
121종에서 플레이 팁 370개, 상대 팁 414개, 스킬 슬롯별 운용 노트 336개를 얻었다.
52종은 문서에 팁 섹션이 없다.

스킬 이름은 en_US 데이터로 한국어로 바꿔 두었지만 **본문은 영문**이다. 그래서 프롬프트에 직접
싣지 않고 **지식 카드를 쓸 때의 원자료**로 쓴다. 서브에이전트가 웹 검색을 반복하는 대신 이 파일을
읽으면 조사 시간이 줄어든다.

같은 문서의 "Recommended Items" 는 수집하지 않았다. 닌자의 신발·뒤틀린 숲처럼 오래전에 사라진
내용이 남아 있어 신뢰할 수 없다. 팁 본문도 최신 패치 기준이 아닐 수 있으므로 지식 카드보다
낮은 우선순위로 다룬다.

## 12. 조언에 반영된 규칙 요약

1. 상대 주 피해 유형과 계수 프로필로 올릴 저항을 정한다.
2. 상대에게 고정 피해가 있으면 저항으로 못 막는다고 명시한다.
3. 상대에게 저항 감소 스킬이 있으면 회피 우선순위를 최상위로 둔다.
4. 내 챔피언 성향으로 아이템 역할군을 좁힌다. 서포터·원거리 딜러 아이템이 브루저 조언에 섞이지 않게 한다.
5. 상대가 평타 의존이면 공격 속도 감소 아이템을, 회복 의존이면 치유 감소 아이템을 후보에 넣는다.
6. 이동기가 없고 상대에게 군중 제어가 많으면 강인함을 저항보다 먼저 고려한다.
