# 리그 오브 레전드 기초 — 스탯과 아이템 체계

> 목적: 상성 조언이 "왜 이 아이템인가"를 근거로 말하려면 스탯이 실제로 어떻게 작동하는지와
> 아이템이 어떤 역할군을 위해 설계됐는지를 알아야 한다. 이 문서는 그 기준을 정리한다.
> 출처는 LoL Wiki(wiki.leagueoflegends.com)와 나무위키 아이템 문서, 그리고 우리 정규화 데이터다.

## 1. 저항과 피해 감소

방어력은 물리 피해, 마법 저항력은 마법 피해를 줄인다. 계산은 동일하다.

```
받는 피해 = 원래 피해 × 100 / (100 + 저항)
저항이 음수면 = 원래 피해 × (2 − 100 / (100 − 저항))
```

핵심은 **실효 체력**이다. 저항 1당 해당 피해 유형에 대한 실효 체력이 1% 늘어난다.
체력 1000에 방어력 25면 물리 피해에 대한 실효 체력은 1250이고, 원래 피해 1000은 800으로 들어온다.

여기서 조언에 직결되는 두 가지가 나온다.

- **저항은 체력과 곱으로 작동한다.** 체력만 쌓거나 저항만 쌓는 것보다 함께 쌓는 것이 실효 체력을 크게 만든다.
  탱커 아이템이 체력과 저항을 함께 주는 이유다.
- **저항은 수익이 체감되지 않는다.** 저항 1당 실효 체력 1%는 저항이 높아도 그대로다.
  "마법 저항력을 더 올려도 소용없다"는 말은 틀렸고, 실제로 소용없게 만드는 것은 아래의 관통과 감소다.

## 2. 관통과 감소, 그리고 적용 순서

같은 "저항 무시"처럼 보이지만 성질이 다르다.

| 구분 | 대상 | 효과 범위 |
|---|---|---|
| 감소(shred) | 대상의 저항 자체를 깎는다 | **우리 팀 전체**에게 적용 |
| 관통(penetration) | 계산할 때만 저항을 낮게 본다 | **그 챔피언의 피해**에만 적용 |

적용 순서는 감소가 먼저, 관통이 나중이고 각 단계에서 비율이 고정보다 먼저다.

```
1) 고정 감소  →  2) 비율 감소  →  3) 비율 관통  →  4) 고정 관통(물리 관통력/치사량)
```

- 고정 감소는 저항을 음수까지 내릴 수 있지만 비율 감소는 0 아래로 내리지 못한다.
- 비율 관통과 물리 관통력은 대상 저항이 0 이하면 아무 효과가 없다.
- 물리 관통력(치사량)은 V14.1 이후 레벨에 비례하지 않는다. 표기된 수치만큼 방어력을 무시한다.

**조언에 쓰는 규칙**

- 상대에게 저항 감소 스킬이 있으면 내 저항 아이템의 값이 실제로 떨어진다.
  그래서 럼블 E 전기 작살처럼 마법 저항력을 깎는 스킬은 회피 우선순위가 가장 높다.
- 고정 관통은 저항이 낮은 대상(딜러)에게, 비율 관통은 저항이 높은 대상(탱커)에게 값을 한다.
  그래서 암살자는 물리 관통력을, 지속 피해형은 비율 관통을 든다.

## 3. 고정 피해

고정 피해는 방어력도 마법 저항력도 줄이지 못한다. 대응 수단은 체력, 회복, 거리 유지뿐이다.
피오라 패시브 급소와 R, 가렌 R처럼 고정 피해가 주력인 스킬을 상대로 저항 아이템을 먼저 사는 것은 잘못된 조언이다.

## 4. 스킬 가속

```
쿨타임 감소율 = 가속 / (100 + 가속)
최종 쿨타임 = 기본 쿨타임 × 100 / (100 + 가속)
```

- 가속끼리는 더하기로 쌓인다. 예전 쿨감(곱연산, 40% 상한)과 다르다.
- 감소율은 100%에 닿지 않는다. 가속 상한은 500(감소율 83.3%)이다.
- 스킬 가속과 궁극기 가속은 더해지며 합계에 같은 상한이 걸린다.

**조언에 쓰는 규칙**: 쿨타임이 긴 핵심 스킬을 가진 챔피언은 가속의 체감이 크다.
반대로 쿨타임이 이미 짧은 스킬 위주 챔피언은 가속보다 피해 스탯이 낫다.

## 5. 공격 속도, 치명타

- 추가 공격 속도는 기본 공격 속도에 비율로 더해진다.
- 공격 속도에는 상한이 있고, 상한을 넘긴 초과분은 일부 스킬 계수로만 환산된다.
- **적의 공격 속도 감소(둔화 계열)는 최종 공격 속도에 곱으로 걸린다.** 그래서 평타 의존 챔피언에게
  얼어붙은 심장이나 마법사의 최후 같은 공격 속도 감소가 강하게 작동한다.
- 치명타는 원거리 딜러 아이템군의 축이다. 치명타 확률 아이템은 평타를 여러 번 넣는 챔피언에게만 값을 한다.

## 6. 강인함

- 군중 제어 지속시간을 줄인다. 상한 100%이고, 어떤 경우에도 지속시간이 0.3초 밑으로는 내려가지 않는다.
- **같은 그룹끼리는 곱, 다른 그룹끼리는 합**으로 쌓인다. 헤르메스의 발걸음 30%와 전설: 강인함 20%를
  더해 50%가 되는 것이 아니라 1 − (0.7 × 0.8) = 44%다.
- 이동기가 없는 챔피언은 군중 제어 한 번에 콤보를 통째로 받는다. 그래서 마법 저항력보다 강인함이 먼저인 경우가 있다.

## 7. 아이템 등급

| 등급 | 특징 | 데이터 판정 |
|---|---|---|
| 소모품·장신구 | 물약, 와드 | `Consumable`, `Trinket` 태그 |
| 시작 아이템 | 도란 계열, 정글 아이템, 여신의 눈물 | 이름과 가격, 조합 관계 |
| 기본 | 조합 재료 | 상위 조합만 있고 하위 조합 없음 |
| 서사 | 부가 효과가 붙기 시작 | 하위·상위 조합 모두 있음 |
| 전설 | 최종 아이템 | 상위 조합 없음 |
| 장화 | 이동 속도 전용 계열 | `Boots` 태그 |

## 8. 아이템 역할군 — 데이터에 없는 것을 만들어야 한다

게임 상점은 아이템을 **브루저·탱커·메이지·원거리 딜러·암살자·서포터** 탭으로 나눠 보여준다.
그런데 DDragon 과 CommunityDragon 데이터에는 그 분류가 없다. 확인한 사실은 다음과 같다.

- CommunityDragon `v1/items.json` 의 필드는 id, name, description, categories, from/to, price 등뿐이고
  `categories` 는 우리 `tags` 와 같다. 즉 스탯 종류만 알려주고 역할군은 알려주지 않는다.
- 역할군별 상점 탭 데이터를 담은 별도 에셋을 찾지 못했다(`shop-item-categories.json` 등 404).
- 근접·원거리 전용 제한도 설명 문구에 일관되게 적혀 있지 않다. 히드라 계열조차 제한 문구가 없다.

그래서 **스탯 조합과 효과 문구로 역할군을 판정**한다. 규칙은 `scripts/llm/lib/itemArchetype.ts` 에 있다.

| 역할군 | 판정 규칙 |
|---|---|
| 서포터 | 오라 태그, 골드 획득 태그, 아군 대상 문구, 아군 지정 필요 |
| 브루저 | 공격력(스탯 또는 "추가 공격력" 문구) + 생존 스탯(체력·방어력·마법 저항력) |
| 탱커 | 생존 스탯만, 또는 저항과 체력을 함께 주고 치명타가 없음 |
| 메이지 | 주문력 + 마나·마법 관통·스킬 가속 |
| 마법 전사 | 주문력 + 체력 |
| 원거리 딜러 | 치명타, 또는 공격력 + 공격 속도 + 생명력 흡수 |
| 암살자 | 공격력 + 물리 관통, 생존 스탯 없음 |

판정에서 주의한 예외

- 스테락의 도전은 스탯이 체력뿐이지만 효과가 추가 공격력을 준다. 문구를 읽어 브루저로 넣는다.
- 마법사의 최후는 마법 저항력을 주지만 공격 속도 아이템이므로 탱커가 아니라 브루저·원거리 딜러다.
- 기사의 맹세는 방어력과 체력을 주지만 아군 대상 아이템이므로 서포터로만 취급한다.
- 오른 업그레이드 등으로 같은 이름이 두 번 등장하므로 이름 기준으로 중복을 제거한다.

## 9. 챔피언 → 선호 역할군

챔피언 카드의 역할 태그, 계수 프로필, 사거리로 결정한다.

| 챔피언 성향 | 선호 | 제외 |
|---|---|---|
| 원거리 딜러 | 원거리 딜러 → 암살자 | 탱커, 메이지, 서포터 |
| 서포터 | 서포터 → 유틸리티 → 탱커 | 원거리 딜러, 암살자 |
| 암살자(AD) | 암살자 → 브루저 | 탱커, 메이지, 원거리 딜러 |
| 메이지(AP) | 메이지 → 마법 전사 | 원거리 딜러, 암살자 |
| AP 전사·탱커 | 마법 전사 → 탱커 | 원거리 딜러, 서포터 |
| 탱커 | 탱커 → 브루저 | 원거리 딜러, 암살자, 메이지 |
| 브루저(AD 전사) | 브루저 → 탱커 | 원거리 딜러, 서포터, 메이지 |

여기에 상대 피해 유형으로 방어 스탯을 고르는 기존 규칙을 곱한다.
예를 들어 아트록스가 피오라를 상대하면 브루저 역할군 중 방어력을 주는 것이 후보가 된다.

## 10. 남는 한계

- **근접·원거리 전용 제한을 데이터로 알 수 없다.** 히드라 계열이 근접 전용이라는 사실은 문구에 없다.
  효과 문구의 "쪼개기", "초승달" 같은 표현으로 근접 성향을 추정하되, 확신이 필요한 항목은 지식 카드에 적는다.
- **메타 적합도는 데이터에 없다.** 어떤 아이템이 현재 강한지는 승률 통계가 필요하다.
  지금은 지식 카드가 그 역할을 하고, 카드가 지목한 아이템을 후보에 고정 포함한다.
- **아이템 효과의 수치 계산은 하지 않는다.** 실효 체력이나 피해량 비교는 시뮬레이션이 필요하고,
  이 프로젝트의 조언은 "왜 이 방향인가"까지만 책임진다.

## 11. 조언에 반영된 규칙 요약

1. 상대 주 피해 유형과 계수 프로필로 올릴 저항을 정한다.
2. 상대에게 고정 피해가 있으면 저항으로 못 막는다고 명시한다.
3. 상대에게 저항 감소 스킬이 있으면 회피 우선순위를 최상위로 둔다.
4. 내 챔피언 성향으로 아이템 역할군을 좁힌다. 서포터·원거리 딜러 아이템이 브루저 조언에 섞이지 않게 한다.
5. 상대가 평타 의존이면 공격 속도 감소 아이템을, 회복 의존이면 치유 감소 아이템을 후보에 넣는다.
6. 이동기가 없고 상대에게 군중 제어가 많으면 강인함을 저항보다 먼저 고려한다.
