# 제품 로드맵

## 제품 목적

게임 시작 전에 내 챔피언과 상대 챔피언의 스킬을 빠르게 확인한다.
사용자는 핵심 쿨타임과 조건을 확인하고 게임으로 돌아갈 수 있어야 한다.

## 현재 화면

- **챔피언 쿨타임 `/`**: 기존 여러 챔피언 비교와 저장된 탭을 유지한다.
- **VS 라인전 비교 `/vs`**: 별도 메뉴에서 내 챔피언과 상대를 선택한다.
  왼쪽은 내 챔피언, 오른쪽은 상대로 고정하고 스크롤 중에도 초상화·이름·역할을 유지한다.
  P·Q·W·E·R 순서로 같은 스킬 키를 같은 행에 배치한다.
  각 스킬은 아이콘·키·이름과 `14 / 12 / 10 / 8 / 6`처럼 연속된 쿨타임 수치를 함께 보여준다.
  랭크 순서·단위 안내는 표 위에서 한 번만 제공하고, 스킬 제목을 누르면 상세가 펼쳐진다.
  게임 중 랭크를 하나씩 선택할 필요가 없으며, 충전 시간은 별도 줄로 구분한다.
  쿨타임 관련 원문 문장을 해당 스킬 아래에 표시하고, 긴 스킬 상세는 같은 셀 안에서 펼친다.
  원문 발췌는 자동 판독이므로 모든 조건을 망라하지 않는다. 전체 설명도 확인할 수 있다.
  같은 키의 스킬을 같은 역할로 간주하거나 짧은 쿨타임을 우세로 표시하지 않는다.
  쿨타임 페이지와 독립적으로 선택을 저장하며 URL 공유·교체·초기화를 지원한다.
  표시 수치는 스킬 가속 적용 전이다. 조건부 쿨타임 변화는 스킬 설명에서 확인한다.
- **룬·아이템 백과 `/encyclopedia`**: 아이템은 능력치, 효과별 설명, 확인된 공식,
  재사용 대기시간, 조합식 순서로 읽는다. 원본 설명은 펼쳐볼 수 있다.
- **기존 시뮬레이션 `/simulation`**: 메뉴와 다른 화면의 진입 버튼에서 제외한다.
  기존 공유 URL과 계산 코드는 보존하며 새 기능 개발의 중심으로 삼지 않는다.

## 정적 페이지의 정보 갱신

### 자동으로 갱신할 정보

`.github/workflows/update-static-data.yml`은 매시간 17분에 원본 확인과 검증·배포를
설정하고 있다. 스케줄은 실행 시각을 보장하는 실시간 서비스가 아니며,
검증 실패 시에는 마지막 검증 데이터를 제공한다.

VS의 스킬 수치는 기존 Ability v2 데이터를 읽는다. 아이템 설명 구조화와
확인된 공식 추출은 `normalizeItems`에서 수행하므로 정기 생성에도 적용된다.
아이템만 다시 생성할 때는 `npm run generate-item-data`를 사용한다.
이 명령은 `public/data/version.json`의 패치를 고정해 다른 데이터와 버전을 맞춘다.

### 사용자 기기에 저장할 정보

향후 개인 매치업 메모와 핵심 스킬 고정은 브라우저 저장소만으로 제공할 수 있다.
서버 없이 동작하지만 기기 간 동기화는 별도 기능이다. 이번 구현에는 포함하지 않는다.

### 검토가 필요한 정보

특정 상대와의 교환 방식, 유불리, 룬·아이템 추천은 쿨타임 데이터만으로 확정하지 않는다.
`knowledge/playbooks`와 `knowledge/tips`는 유지하되 현재 VS에서 자동 노출하지 않는다.

추후에는 각 조언에 참조하는 챔피언·스킬·아이템과 검토 패치를 연결한다.
패치가 바뀌었을 때 의존 데이터가 바뀐 조언을 검토 대상으로 표시하는 방식을 우선한다.
새 패치 번호를 붙이는 것만으로 기존 조언을 검증된 최신 정보로 취급하지 않는다.

## 다음 검증

1. 실제 사용자에게 상대 조합을 주고 30초 안에 필요한 쿨타임을 찾는지 확인한다.
2. 반복 조회하는 핵심 스킬과 개인 메모 수요를 확인한다.
3. 자주 사용하는 매치업부터 검토한 짧은 상대법을 추가한다.
4. 반복해서 확인하는 상황이 드러나면 해당 상황에 한정한 계산을 설계한다.

## 완료 기준

- 기존 쿨타임 선택과 VS 선택이 서로 덮어쓰지 않는다.
- VS 직접 진입·새로고침·공유·교체·초기화가 동작한다.
- 세 언어와 모바일에서 두 챔피언을 함께 볼 수 있고 가로 넘침이 없다.
- 스크롤 후에도 내 챔피언과 상대가 어느 열인지 식별되며, 모바일에서도 스킬 아이콘과 이름을 숨기지 않는다.
- 랭크 선택 없이 전체 쿨타임이 보이며, 3랭크 궁극기·6랭크 스킬·충전형 스킬을 구분한다.
- 기본 아트록스·피오라 조합은 900px 높이 데스크톱 첫 화면에서 P~R을 함께 확인할 수 있다.
- 아이템 효과 이름·설명·공식이 분리되고 능력치를 중복 출력하지 않는다.
- 확인되지 않은 계산을 임의의 숫자로 채우지 않는다.
- 원본 수치와 조언의 검증 상태를 구분한다.
