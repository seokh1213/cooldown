# 제품 로드맵

## 제품 약속

cooldown은 최신 패치의 스킬 정보를 빠르게 비교하고, 사용자가 선택한 조건으로
콤보 피해와 킬각을 재현하는 정적 웹 도구다. 숫자를 많이 보여주는 것보다
출처, 조건, 계산 가능 범위를 분명히 보여주는 것을 우선한다.

핵심 흐름은 다음과 같다.

1. 챔피언과 스킬을 비교한다.
2. 아이템·룬·소환사 주문과 대상을 선택한다.
3. 스킬 랭크와 사용 횟수, 대상 방어 능력치를 조정한다.
4. 조건이 명시된 피해 합계와 킬각을 확인한다.
5. 같은 상태를 링크로 저장하거나 공유한다.

## 현재 기준

- DDragon과 CDragon을 CI에서 받아 Ability v2 정적 데이터로 생성한다.
- 본문, 비용, 쿨다운, 레벨값, 계수, 발동 조건과 미해결 진단을 분리한다.
- 브라우저는 검증된 선형 피해식만 계산한다.
- 룬·아이템·소환사 주문의 직접 피해를 콤보에 포함한다.
- 한국어, 영어, 중국어와 데스크톱·모바일을 지원한다.
- PWA는 앱 셸만 미리 저장하고 패치 데이터는 사용한 항목부터 캐시한다.

## 완료된 제품 흐름

### 재현 가능한 시뮬레이션 링크

공격자·대상·레벨·아이템·룬·주문·스킬 랭크·횟수·방어 입력과 제외 조건을
버전이 있는 URL 상태로 저장한다. 알 수 없는 현재 패치 항목은 안전하게 제거하며,
공유 버튼은 복사 성공과 실패를 접근 가능한 상태 메시지로 알린다.

### 조건 토글과 계산 근거

비열한 한 방, 3타, 적중 시 같은 조건부 행을 사용자가 적용하거나 제외할 수 있다.
제외된 피해는 합계에서 빠지고 URL에도 상태가 보존된다. 스킬 화면은 Ability v2의
현재 기본값, 스킬 랭크, 챔피언 레벨 계수와 스탯 계수를 산식으로 보여준다.

### 화면 연결·프리셋·신뢰도

- 비교 화면의 챔피언/VS 조합을 시뮬레이션으로 넘긴다.
- 아이템 백과의 선택 항목을 시뮬레이션 첫 슬롯으로 넘긴다.
- 레벨 6·11·16·18과 대상 체력 25·50·100% 프리셋을 제공한다.
- 패치, 계산 가능 스킬 수, 조건부 및 제외 항목 수를 작업 화면 상단에 표시한다.

### 제품 사용 지표

시뮬레이션 복원, 공격자·대상 선택, 결과 도달, 공유, 조건 변경 이벤트를
개인 식별자 없이 기록한다. 기본 상태에서는 브라우저 이벤트만 발생하며,
`VITE_PRODUCT_METRICS_ENDPOINT`가 설정된 배포에서만 같은 출처 정책과 별개인
집계 엔드포인트로 최소 이벤트를 전송한다.

## 다음 우선순위

### P1 — 시간축과 반복 피해

채널링, 지속 피해, 다단 적중을 `1회 피해`와 `전체 피해`로 구분한다.
짧은 콤보 타임라인에서 스킬 순서와 경과 시간을 입력하고 쿨다운 재사용 여부를 검증한다.
보호막, 회복, 잃은 체력과 처형 기준은 피해와 별도 단계로 계산한다.

### P1 — 신뢰도와 계산 범위

미해결 토큰은 사용자에게 필요한 경우에만 진단으로 노출한다.
비선형 계산, 버프 중첩, 치명타·스택 의존식은 필요한 런타임 입력을 먼저 설계한 뒤 지원한다.
피해가 없는 유틸리티 스킬은 `계산 불가`가 아니라 `직접 피해 없음`으로 구분한다.

### P2 — 매치업 안내

검증된 스킬·조건 데이터에서 결정론적 위험 요소와 대응 포인트를 먼저 만든다.
정적 지식 카드는 패치와 출처를 명시하고 CI 검증을 통과한 것만 배포한다.
약 2.5GB 모델을 요구하는 브라우저 로컬 LLM은 기본 기능이 아닌 명시적 동의 기반 실험으로 둔다.

## 운영 지표

- 최신 패치 배포와 공개 Pages 검증 성공
- 예상 밖 미해결 토큰 0개
- 모바일 가로 오버플로 0개
- 깨끗한 브라우저에서 Service Worker 준비 5초 이내
- 공유 링크 복원 후 계산 결과 완전 일치
- 조건이 가정된 피해의 무표시 합산 0건

## 하지 않는 것

- 근거 없는 수치 보간이나 미지원 계산식의 0 처리
- 패치가 다른 데이터를 한 계산에 혼합
- 대용량 모델을 동의 없이 다운로드
- 서버가 필요한 기능을 프론트 전용 Pages에 억지로 숨겨 넣기
