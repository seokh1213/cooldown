# 패치 변경 내역 렌더링

빌드 프로토타입: `http://127.0.0.1:4173/cooldown/patch-notes`

현재 배치는 챔피언 → 스킬 → 변경 항목·수치 순서다. PC 오른쪽에 버전 목차를
유지하고 제목 아래 간격과 챔피언 사이 여백을 줄였다. 모바일은 버전 선택을
상단에 둔다. 표로 묶었던 `compact` 시안은 사용하지 않는다.

## 현재 캡처

- `desktop-revised.png`: 1440 × 1050, 챔피언별 구성과 오른쪽 버전 목차.
- `desktop-revised-dark.png`: 동일한 구성의 다크 모드.
- `desktop-stat-glyph.png`: 공격력 변경 `62 → 64`와 공통 공격력 글리프.
- `desktop-skill-hover.png`: 기존 공통 컴포넌트로 표시하는 PC 스킬 미리보기.
- `desktop-revised-items.png`: 협곡 아이템 변경과 체력·재생 글리프.
- `desktop-aphelios-icons.png`: 패치 프래그먼트로 직접 연 위치와 서로 다른 다섯 무기 아이콘.
- `mobile-revised.png`: 390 × 844, 공식 링크·버전 선택·챔피언별 수치.
- `mobile-skill-dialog.png`: 모바일 탭 상세창과 본문 스크롤 영역.
- `mobile-320-dialog.png`: 320px에서도 제목과 쿨타임을 읽을 수 있는 상세창.
- `mobile-revised-26.18.png`: 26.18에 해당하는 실제 변경 11건.

`before-density.png`는 최초 간격을 확인하는 비교 자료다. 그 외 초기·`compact`
PNG는 이전 시안 기록이다. PC 첫 수치는 약 760px에서 500px로 올라왔다.

## 검증

- 현재 패치, 43개 버전 기록, 26.18 챔피언 8종·수치 11건의 전환.
- 공식 링크가 PC·모바일에서 요청한 게임 업데이트 목록 주소로 연결됨.
- 스탯 글리프가 실제 이미지로 로딩됨. 원본 링크·다운로드·판본 안내는 노출하지 않음.
- PC 호버 미리보기 하나만 노출. 같은 Q 슬롯을 쓰는 개별 무기도 서로 닫힘.
- PC 클릭·모바일 탭으로 공통 상세창 표시, 닫으면 스킬로 포커스 복귀.
- 상세창을 닫은 뒤 포인터가 그대로 있어도 미리보기가 다시 열리지 않음.
- 모바일 전환 시 PC 미리보기 닫힘. 모바일 스킬 버튼은 높이 44px 이상.
- 320·390·768·1024·1440px와 한국어·영어·중국어에서 가로 넘침 없음.
- 과거 스킬은 해당 버전의 JSON을 로딩. 26.18 카시오페아 Q의
  `65 / 100 / 135 / 170 / 205` 수치를 상세창에서도 확인.
- 챔피언 요약 링크는 패치와 프래그먼트를 보존. 새로고침·뒤로가기·앞으로가기,
  필터 상태와 모바일 탭까지 패치 브라우저 테스트 7건으로 확인.
- 별도 스킬 아이콘이 실제로 로딩되고, 호버·상세창에서도 해당 무기 이미지 유지.
- 전체 데이터·단위 검증, 타입 검사·lint 통과.
- 빌드·Pages 경로 산출물 확인. 공개 보고서·스킬 JSON은 배포본과 바이트가 같고
  PWA 설치 캐시에 포함됨. 내부 원본·스냅샷·검토·스킬 카탈로그는 배포되지 않음.
- 실제 빌드 결과의 PC·모바일 렌더링과 브라우저 오류 없음 확인.

25.1~25.24, 26.1~26.19 보고서 43개와 3개 언어의 스킬 JSON 129개를 보관했다.
CI는 감지한 현재 판본과 누락된 보고서를 생성·보관한 뒤 Pages에 배포한다.
현재 생성 명령 재실행 시 내부 보관 파일 306개가 유지됨을 확인했다.
