# anti-slop Delivery Gate

주 에이전트가 실제 production bundle과 회귀 테스트를 직접 확인했다. 이 판정은 승인한 B·C·D, 연결된 기능·접근성 복구, 별도 표시한 E 검토 시안의 전달 범위에 적용한다. 기존 앱 전체의 모든 디자인·게임 문구·GPU 기능을 보증하는 판정은 아니다. E의 패치 출처 문제는 앱에 미적용 상태로 별도 공개한다.

Design Read: LoL 자료를 읽고 비교하는 도구, 기존 게임 이미지·표·선택 강조와 라이트/다크를 유지한다. ENERGY 1 / RHYTHM 1 / MOTION 1. 새 시각 방향을 만들지 않고 승인된 포커스·조작 영역·오류 상태와 기능 복구를 적용한다.

근거: [직접 실행 기록](applied-evidence/root-visual-verification.json), [전체 검증](applied-evidence/verification-summary.json), [파일 검토](applied-evidence/coverage-files.json). 해당 E2E는 `ui-accessibility`, `encyclopedia-load-retry`, `item-detail-focus`, `cooldown-detail-retry`, `advisor-loading-recovery`, `advisor-mobile-layout`, `route-loading-recovery`, `sanitizer-security`, `pwa-updates`다. 스크린샷 다섯 장은 주 에이전트가 이미지로 열어 실제 구성을 확인했다.

## 1. Hard Gate

- R-02 PASS: 추가한 제품 문구는 기존 번역의 오류·재시도이며 em dash를 넣지 않았다. E의 작성 문구도 확인했다.
- R-03 PASS: 7개 화면 × 5개 폭(360·390·768·1024·1440px) × 2개 테마 70개에서 가로 넘침 0개. 360px VS·1440px 룬·390px 오류/도우미·360px E 이미지에서 줄바꿈과 컨테이너를 직접 확인했다.
- R-17 PASS: 새 고객·이용률·성능 통계를 제품에 넣지 않았다. 보고서의 JS 숫자는 파일별 bytes 목록에 근거한다.
- R-18 PASS: 후기·인물·AI 얼굴을 생성하거나 추가하지 않았다.
- R-23 PASS: 기존 LoL 이미지·아이콘·메뉴 항목을 사용했다. E의 38·40과 26.18·26.19는 명시적으로 재현 예시인 검토 시안이며 제품 데이터로 넣지 않았다.
- R-24 PASS: 기존 메뉴 목적지를 실제 클릭했고 실패한 페이지 JS에서도 정상 목적지 이동을 확인했다. 새 가상 링크는 없다.
- R-25 PASS: 실제 테마 CSS를 브라우저에서 해석해 추가 오류 문구에 사용하는 기본/보조 텍스트가 4.5:1 이상임을 확인했다. 보조 텍스트는 라이트 4.65:1, 포커스는 라이트 6.19:1·다크 4.62:1이다. 별도 포커스 E2E가 실제 shared control 링의 alpha 255·대비 3:1 이상을 확인했다.
- R-26 PASS: 적용한 공유·교체·초기화·닫기·탭·재시도에 실제 동작이 있다. 룬 터치·Enter, 챔피언 Enter·Space, Retry 후 정상 카탈로그를 실행했다.
- R-27 PASS: 카탈로그 loading·HTTP/JSON/schema error·valid empty와 실제 재시도를 각각 검사했다. 자료·라우트 모듈·저장 대화 실패에도 복구 경로를 확인했다.
- R-28 PASS: 무관한 FAQ를 추가하지 않았다. 기존 게임 도구의 도움말 동작을 확인했다.
- R-32 PASS: Tab·Shift+Tab·Enter·Space·Escape, 모달 포커스 고정·복귀, 불투명 포커스, 메뉴 배경 inert 해제를 해당 E2E로 확인했다.
- R-33 PASS: 기능은 앱 소스에 구현했다. 브라우저 스타일 변형은 승인 전 비교 시안에만 사용한 것이며 적용 코드에는 없다.
- R-34 PASS: 정상 화면 70개와 D 오류 6개에서 두 테마를 확인했다. 반응형 크기·링 대비·오류 텍스트를 실행으로 검사했다.
- R-35 PASS: 타입·lint·단위·production build와 브라우저 실행을 수행했다. 적용 컨트롤의 클릭·터치·키보드와 오류 회복은 테스트 파일에 기록했다.
- R-36 PASS: 접근성·보안·체감 속도의 포괄 보증 문구를 제품에 추가하지 않았다. 초기 JS와 PWA 전체 사전 캐시를 구분하고 GPU 미실행을 보고했다.
- R-37 PASS: 기존 화면과 승인한 B·C·D를 방향으로 삼았다. 새 E는 “검토용이며 앱에는 적용하지 않았습니다”로 표시한 시안이다.
- R-38 PASS: 실제 게임 자료를 사용하고 새 허구의 팀·고객·기능·게임 통계는 없다. E의 예시 값은 첫 문단에서 표시했다.

## 2. Purpose Gate

- R-01 PASS: 새 배경 그라데이션·광채가 없다. 기존 launcher의 conic 표현은 실제 모델 다운로드 진행률에만 쓰인다.
- R-04 PASS: MessageCircle·교체·공유·닫기 등 기존 아이콘의 역할을 유지했다. C는 아이콘 16px을 유지하고 조작 영역만 바꾼다.
- R-06 PASS: 기존 글꼴과 숫자 표를 유지했다. 모노스페이스·대문자 마케팅 라벨을 추가하지 않았다.
- R-07 PASS: 새 장식 배경·격자·점 무늬가 없다. 기존 표 격자는 게임 수치를 비교하는 구조다.
- R-08 PASS: 장식 화살표를 새 버튼에 반복하지 않았다. E는 출처를 글로 구분한다.
- R-09 PASS: Beta·AI Powered 등 장식 배지를 추가하지 않았다. 기존 선택/상태 표시는 실제 기능을 따른다.
- R-10 PASS: 새 glassmorphism이 없다. 오류 안내는 읽을 수 있는 기존 배경과 테두리를 쓴다.
- R-12 PASS: 각 카드에 새 큰 그림자를 붙이지 않았다. 기존 떠 있는 도우미·상세창의 그림자는 화면 높이 구분을 유지한다.
- R-13 PASS: UI 전체에 광채를 추가하지 않았다. B의 링은 키보드 위치를 드러낸다.
- R-14 PASS: 템플릿 feature card를 추가하지 않았다. 기존 게임 분류·비교 표·상세창의 콘텐츠 구조를 따른다.
- R-19 PASS: 새 자동 움직임을 추가하지 않았다. 기존 상태 표시와 전환을 유지하며 launcher에는 motion-reduce 처리가 있다.
- R-22 PASS: 새 일반 일러스트나 생성 이미지를 넣지 않았다. 이미지 식별은 기존 게임 자산을 사용한다.

## 3. Liveliness Gate

- Dials PASS: ENERGY 1 / RHYTHM 1 / MOTION 1을 선언했고 기존 자료 도구의 정보 밀도와 조작을 유지했다.
- Consistency PASS: 승인한 B·C·D는 포커스·조작·복구에 한정한다. 새 히어로·리빌·움직이는 장식이 없다.
- Focal point PASS: VS의 비교 표, 룬 분류, 오류의 재시도, 도우미의 대화/입력처럼 화면별 작업 중심이 명확하다. 직접 연 이미지로 확인했다.
- Whitespace PASS: 기존 분류·표·도구 영역 사이 간격을 유지한다. D는 실패 안내와 다음 행동을 같은 행에 둔다.
- Accent PASS: 기존 보라색은 선택 탭·포커스·대화/주요 동작에 사용한다. 다른 강조색을 새로 만들지 않았다.
- Identity PASS: 실제 챔피언/룬 이미지, 랭크·레벨별 표와 게임 용어가 반복되는 제품 문법을 유지한다.
- Design Read PASS: 기존 LoL 비교·참조 도구와 승인 방향을 선언하고 시안과 코드에서 같은 기준을 사용했다.

## 4. Craftsmanship & Quality Locks

- C-1 PASS: B는 키보드 위치, C는 손가락 조작, D는 실패 인지·회복을 위한 결정이다. 장식 목적의 임의 결정이 없다.
- C-2 PASS: 변경한 컨트롤은 실제 이벤트/목적지가 있고 결과를 실행했다. 재시도 버튼은 정상 데이터 복구까지 검사했다.
- C-3 PASS: 자료·대화·오류 회복에 필요한 요소만 추가했다. 템플릿을 채우는 섹션을 만들지 않았다.
- C-4 PASS: 적용 범위의 테마·폭·loading/error/empty·키보드·터치·오프라인 회귀를 확인했다. 모바일 portal의 훅 연결 회귀도 수정하고 기존 스크롤·키보드 높이 테스트를 통과시켰다.
- C-5 PASS: 게임 자료·예시·측정을 구분했다. 실측하지 않은 속도·GPU 메모리·전체 버그 부재를 주장하지 않는다.
- R-05 PASS: 기존 게임 도구의 표·분류·참조 패널 구조를 유지하고 일반 랜딩 템플릿을 추가하지 않았다.
- R-11 PASS: 버튼·표·상세창은 기존 각진 정도를 유지하고 떠 있는 launcher만 기존 원형이다.
- R-15 PASS: 새 제품 CTA는 실제 행동인 기존 “다시 시도”다. 일반적인 마케팅 CTA를 추가하지 않았다.
- R-16 PASS: 새 마케팅 과장 문구가 없다. E의 문구는 작성 패치와 현재 자료를 구분한다.
- R-20 PASS: 실제 LoL 게임 자산·수치·룬·챔피언 비교 구조가 제품의 정체성을 유지한다.
- R-21 PASS: 사용자의 저장 테마와 시스템 선택을 유지하며 라이트·다크를 모두 검사했다.
- R-29 PASS: 기존 중립색과 보라색 강조를 유지한다. 게임 자산의 의미 색상은 보존하고 새 UI 팔레트를 만들지 않았다.
- R-30 PASS: 다른 인기 제품을 모방하거나 새 템플릿으로 교체하지 않았다.
- R-31 PASS: 색은 기존 선택/포커스, 배치는 기존 비교 작업, 글꼴은 기존 수치/용어, 간격은 조작 영역과 분류, 이미지는 게임 식별을 위한 것이다. 각 결정의 이유를 APPLIED.md와 위 항목에 기록했다.
