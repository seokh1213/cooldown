# 과거 카드 수정 Delivery Gate

주 에이전트가 수정한 production bundle의 실제 화면과 동작을 직접 검사했다. 아래 판정은 과거 카드 복원, 출처 구분, 저장 실패 안내의 범위에 적용한다. 앱 전체의 모든 디자인·게임 사실·모델 기능에 대한 보증은 아니다.

Design Read: 기존 LoL 자료 비교 도구의 카드·표·게임 이미지·라이트/다크를 유지한다. ENERGY 1 / RHYTHM 1 / MOTION 1. 사용자에게 필요한 변화는 당시 자료의 보존과 실패 인지이며, 기존 구성 안에서 출처 표기와 저장 안내를 추가한다.

근거: [복원 수정](HISTORY-FIX.md), [직접 화면 검사](history-evidence/root-history-visual.json), [저장 실패와 키보드 재시도](history-evidence/root-history-quota.json), [통합 검증](history-evidence/verification.json). 새 E2E는 `advisor-history-snapshots`이며, 기존 대화·자료 탭·스킬·로딩·키보드·PWA 검사도 실행했다. 주 에이전트는 모바일 다크 카드, 데스크톱 라이트 카드, 모바일 원본 없음, 모바일 저장 실패 이미지를 직접 열어 확인했다.

## 1. Hard Gate

- R-02 PASS: 새 한국어·영어·중국어 안내에 em dash를 넣지 않았다. 출처와 실패를 짧은 문장으로 설명한다.
- R-03 PASS: 5개 폭 × 두 테마 × 카드/원본 없음 상태 20개에서 문서 가로 넘침 0개다. 360px 저장 실패에서도 재시도 버튼이 화면 안에 있다.
- R-17 PASS: 제품에 새 이용률·성능 수치를 넣지 않았다. 검증 수치는 실행 기록에서 확인한다.
- R-18 PASS: 인물·후기·AI 얼굴을 추가하지 않았다. 자료 카드에는 기존 게임 자산을 사용한다.
- R-23 PASS: 새 제품 이미지나 아이콘을 만들지 않았다. 테스트 수치 601·602·111·222는 E2E 분리 검사용이며 실제 배포 자료는 변경하지 않았다.
- R-24 PASS: 과거 카드의 “현재 자료로 이동”을 실제 클릭해 `/vs?a=MonkeyKing`으로 이동하고, 모바일에서는 도우미가 닫히는 것을 확인했다.
- R-25 PASS: 새 표기는 기존 `text-muted-foreground`와 배경을 사용한다. 이전 직접 대비 검사에서 보조 텍스트 라이트 4.65:1, 포커스 라이트 6.19:1·다크 4.62:1을 확인했고, 관련 테마 CSS는 변경하지 않았다. 두 테마 이미지를 다시 확인했다.
- R-26 PASS: 중복 탭 전환, 현재 자료 링크, 저장 재시도를 실행했다. 카드·상세 수치와 저장 결과를 확인했다.
- R-27 PASS: 과거 원본 없음과 저장 실패를 구분한다. 복원할 수 없는 원본은 그 이유를 표시하고 대화는 유지한다. 저장 실패는 공간 확보·재시도·페이지 종료 시 유실 가능성을 함께 안내한다.
- R-28 PASS: 관련 없는 FAQ를 추가하지 않았다. 복원 실패 설명은 해당 답문 옆에 있다.
- R-32 PASS: 재시도 버튼을 포커스한 뒤 Enter로 저장 성공을 확인했다. 기존 모달 Tab·Shift+Tab·Escape·복귀 회귀도 실행했다.
- R-33 PASS: 동작은 제품 소스에 구현했다. DOM에 임시 스타일을 넣어 결과를 꾸미지 않았다.
- R-34 PASS: 정상 카드·원본 없음·저장 실패를 라이트와 다크에서 확인했다.
- R-35 PASS: 실제 원본 저장→새로고침→당시 마나 복원, 다른 패치 탭 전환, 최신 상세 요청 0건, 자료 장애 중 복원, 용량 실패 후 재시도를 브라우저에서 확인했다. 타입·lint·단위·빌드 검사도 실행했다.
- R-36 PASS: 모든 옛 카드가 복구된다고 주장하지 않는다. 저장되지 않은 원본과 다운로드에 실패한 상세 자료의 한계를 보고서에 명시했다.
- R-37 PASS: 사용자의 “당시 대화와 당시 카드” 요청을 방향으로 적용했다. 기존 카드 구성은 유지하고 필요한 출처·실패 표기만 추가했다.
- R-38 PASS: 실제 게임 자료를 저장하고 복원한다. 검사용 변경 값은 테스트 코드와 보고서에만 있으며 제품 자료를 허구의 값으로 바꾸지 않았다.

## 2. Purpose Gate

- R-01 PASS: 기존 중립 배경과 강조색을 유지한다. 추가 안내는 원본·저장 상태를 이해시키는 역할을 한다.
- R-04 PASS: 기존 게임 아이콘과 버튼 아이콘을 유지한다. 재시도는 실제 저장 행동을 나타낸다.
- R-06 PASS: 기존 글꼴과 숫자 표 문법을 유지한다. 출처는 기존 작은 보조 글씨로 구분한다.
- R-07 PASS: 추가 장식 배경은 없다. 표의 선은 스탯 행을 구분한다.
- R-08 PASS: 새 안내에 장식 화살표를 추가하지 않았다. 기존 이동 링크는 실제 목적지가 있다.
- R-09 PASS: 추가 배지는 없다. 탭의 패치·언어·자료 버전은 중복 자료 구분에 필요한 내용이다.
- R-10 PASS: 저장 오류는 기존 불투명 배경 위에 표시한다. 새 투명 효과를 넣지 않았다.
- R-12 PASS: 카드와 오류에 새 그림자를 추가하지 않았다. 기존 떠 있는 도우미 구성은 유지한다.
- R-13 PASS: 새 광채는 없다. 포커스 링은 키보드 위치를 표시한다.
- R-14 PASS: 카드의 콘텐츠 구조는 실제 스탯·스킬·출처를 따른다. 정해진 템플릿을 채우는 섹션을 만들지 않았다.
- R-19 PASS: 새 자동 애니메이션은 없다. 원본이 없는 옛 답에 진행 중 스피너가 남지 않는 것을 검사했다.
- R-22 PASS: 이미지는 기존 챔피언과 스킬을 식별한다. 관련 없는 일러스트는 없다.

## 3. Liveliness Gate

- Dials PASS: ENERGY 1 / RHYTHM 1 / MOTION 1로 기존 정보 밀도와 상호작용을 유지한다.
- Consistency PASS: 변경 범위는 과거 자료·출처·저장 상태다. 실제 스크린샷에서도 카드 배치와 표 문법을 유지한다.
- Focal point PASS: 과거 대화는 당시 답문, 자료 패널은 선택한 당시 카드, 저장 실패는 재시도가 중심이다.
- Whitespace PASS: 기존 카드·표·대화 간격을 유지하고 실패 문구와 재시도를 같은 영역에 둔다.
- Accent PASS: 기존 선택 탭과 포커스 강조를 유지한다. 출처 보조 글씨는 중립색이다.
- Identity PASS: 챔피언 초상·스킬 슬롯·레벨별 성장 수치와 게임 용어가 기존 제품을 식별한다.
- Design Read PASS: 기존 자료 비교 도구의 방향과 사용자 요청을 선언하고 실제 화면으로 확인했다.

## 4. Craftsmanship & Quality Locks

- C-1 PASS: 원본 보존은 정확성, 탭 표기는 자료 식별, 오류 안내는 유실 방지라는 이유가 있다.
- C-2 PASS: 원본 카드와 상세 자료를 검증하고, 실제 전환·이동·저장 결과까지 확인했다.
- C-3 PASS: 답문·카드·출처·실패 안내는 사용자가 대화를 다시 읽는 작업에 필요하다.
- C-4 PASS: 초기 로딩·원본 없음·상세 없음·저장 실패와 지원 폭·테마를 확인했다. 자료가 없어도 옛 기록을 읽고 새 질문은 자료 준비를 기다린다.
- C-5 PASS: 원본 없는 기록과 이미지 자산 보관의 한계를 명시했다. 단순 코드 검토를 실제 복원 성공으로 표현하지 않았다.
- R-05 PASS: 기존 표와 자료 패널을 유지한다. 새로운 랜딩 페이지 구조를 추가하지 않았다.
- R-11 PASS: 기존 카드·버튼의 테두리와 둥근 정도를 유지한다.
- R-15 PASS: 새 버튼의 이름은 실제 행동인 “저장 다시 시도”다.
- R-16 PASS: 과장 문구가 없다. “당시 카드 원본이 저장되지 않아 복원할 수 없습니다”로 원인을 정확히 알린다.
- R-20 PASS: 실제 게임 자료와 카드·표 구조가 기존 서비스의 목적을 유지한다.
- R-21 PASS: 저장한 테마를 유지하고 라이트·다크 모두 확인했다.
- R-29 PASS: 기존 중립색과 선택 강조색을 유지한다. 새 팔레트를 만들지 않았다.
- R-30 PASS: 다른 제품의 UI로 교체하지 않았다. 기존 자료 패널을 유지한다.
- R-31 PASS: 표는 수치 비교, 아이콘은 챔피언·스킬 식별, 작은 글씨는 출처 구분, 실패 행은 다음 행동을 위한 것이다. 각 결정과 실행 근거를 위 항목에 기록했다.
