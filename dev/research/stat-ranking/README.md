# 챔피언 능력치 순위 페이지 시안

현재 앱의 배경색·강조색·로고·챔피언 이미지를 사용하는 독립 HTML 시안이다. 운영 페이지의 경로는 아직 추가하지 않았다.

## 확인

프로젝트 루트에서 `python3 -m http.server 4191 --bind 127.0.0.1`을 실행하고 `/research/stat-ranking/prototype.html`을 연다.

- 표 / 막대 보기 전환
- 일곱 능력치, 1–18레벨, 공식 역할군, 이름 검색
- 같은 수치는 공동 순위, 검색·역할군 필터 후에도 전체 순위 유지
- 두 명 선택 후 운영 VS 화면에서 비교
- 모바일에서는 역할군 열을 숨기고 성장치를 수치 아래에 배치

데이터를 갱신하려면 `python3 dev/research/stat-ranking/generate.py`를 실행한다. 정규화된 `baseStats`와 공식 역할군만 내보낸다. 아이템·룬·고유 패시브·변신에 따른 추가 보정은 적용하지 않는다.

## 확인한 디자인

표 보기는 수치와 성장치를 함께 읽기 좋고, 막대 보기는 차이를 빠르게 훑는 데 쓴다. 챔피언 수를 세거나 상위 퍼센트를 강조하는 대신 현재 레벨의 실제 수치를 보여준다. 상단 조건은 스크롤을 따라 고정하지 않고, 비교 선택만 하단에 유지한다.

`preview-1440.png`, `preview-390.png`, `preview-bars.png`에서 두 보기와 모바일 배치를 확인할 수 있다.

390px·1440px에서 173명 표시, 이름 검색, 18레벨 성장값, 두 명 선택과 VS 주소, 빈 검색 결과·초기화, 막대 전환을 브라우저로 확인했다. 가로 넘침과 페이지 오류는 없었다. `preview-bars-selected.png`, `preview-390-selected.png`는 실제 비교 선택 상태다.
