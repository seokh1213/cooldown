# 공식 패치 대조와 누락 복원, 2026-10-08

공식 협곡 밸런스와 배포 전 보고서를 대조했다. 기준 커밋은 `1b933e311db4f0b9852041fbe40f538b7e851810`이다.
정확한 대상·수·원문 해시·아이템 필드 대조는 [audit.json](audit.json)에 있다.

## 확인한 누락

26.20은 공식 챔피언 16종 중 9종만 표시했다. 암베사·다이애나·케넨·니코·스몰더·탐 켄치·유나라가
완전히 빠졌고, 실험적 마공학판·마법공학 로켓 벨트·루난의 허리케인도 모두 빠졌다.
이미 표시되던 킨드레드 W의 몬스터 계수와 E 대상 지정, 크산테 W 피해 감소,
모데카이저 Q 성장 등도 부족했다. 수정 후 챔피언 16종·아이템 3종, 공식 34행을 표시한다.

26.19는 마스터 이의 재사용 대기시간 반환 방식과 순간이동 체계를 누락했다.
아펠리오스는 레벨 구간·스킬 공격 회복·쿨타임 배열·최소 피해량 조건 일부만 표시했고,
피오라 회복량의 공식 단위·최대치도 온전히 전달하지 못했다.
오로라 R은 원본 게임 배열에서 선택한 인덱스가 공식 표기와 달랐다.
수정 후 챔피언 17종·아이템 2종·게임 체계 1종, 공식 41행을 43개 항목으로 표시한다.
공통 아이템 2행을 아이템별로 나눈 것이 41→43의 이유다.

## 원인과 수정

1. `spellMetrics`가 등록된 수치 키만 읽었다. 26.20의 검토 파일에는 이미 미매핑 14필드가 있었지만
   화면은 이 목록을 사용하지 않았다. 데이터가 전부 다운로드되지 않은 문제가 아니라 비교 범위의 문제였다.
2. 스킬 내부 `DataValues`·`mSpellCalculations`와 아이템 기본 능력치만 수집했다. 동작 규칙,
   별도 스크립트·아이템 효과·게임 체계는 숫자 비교만으로 표현할 수 없었다.
3. 같은 길이의 배열에도 기본 인덱스·스킬 랭크·챔피언 레벨 등 의미가 달랐다.
   공식 원문의 전후 문장과 조건을 보존해 오로라·아펠리오스·탐 켄치처럼 공식 표기를 재현할 수 없는 경우를 해결했다.
4. 아이템 가속 키는 실제로 `mAbilityHasteMod`다. 생성기는 `AbilityHasteMod`를 읽어 0으로 채웠다.
   두 CDragon 판본의 로켓 벨트 실제 값 20→10과 스냅샷 0→0을 직접 대조하고 키를 수정했다.
5. 기존 테스트는 같은 제한된 스냅샷과 보고서를 대조했으므로 누락해도 통과했다.
   이제 공식 원문의 모든 행·3언어 대응·공개 결과의 행 식별자를 별도로 검사한다.

앞으로 현재 패치 생성은 공식 sitemap에서 URL을 찾고 공식 원문을 함께 수집한다.
공식 페이지의 중복 heading ID를 재사용하지 않고 실제 대상 이름으로 게임 ID를 연결한다.
다른 게임 모드·스킨·클라이언트 공지·일반 버그 수정과 점수판 숫자 숨김 목록은 협곡 밸런스에 섞지 않는다.
중국어는 대만 공식 원문이다. 원문의 대상·행 수 또는 숫자가 번역과 다르면 생성이 실패한다.
같은 패치의 추가 공지·핫픽스 갱신과 이전 전체 연도 보완은 이번 작업 범위에 포함하지 않는다.

숫자 비교용 원본과 스냅샷은 바이트 단위로 그대로 유지했다. 내부 미매핑 14필드는 원래 수집 범위의
검토 기록이며, 현재 공개 보고서가 14항목을 여전히 누락한다는 의미가 아니다.
공식 전후 문장 출처는 `sourceKey`와 `officialSource`에, 기존 스킬 이미지 연결은 별도 `gameDataKey`에 둔다.
기존 스킬 상세를 보존하면서 새로 추가된 스킬 그룹만 채운다.
