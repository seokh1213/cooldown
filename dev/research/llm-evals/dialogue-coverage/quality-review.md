# 답변을 직접 읽은 품질 검토

자동 계약 검사를 통과한 뒤에도 답을 읽고 근거 자료와 대조했다. 이 기록은 구현한 에이전트의 직접 검토이며 외부 사용자 평가나 블라인드 심사가 아니다.

## 기준

| 항목 | 0점 | 1점 | 2점 |
|---|---|---|---|
| 요청 충족 | 핵심 요청 누락/대상 변경 | 일부만 답함 | 각 요청에 답 또는 해당 부분 안내 |
| 사실 | 잘못된 값/대상 | 근거 범위·단위 불분명 | 패치 카드/노트와 일치 |
| 조건 | 부재 스킬 사용 요구 | 조건 연결 불명확 | 주인·상태를 유지하고 가능한 행동만 제시 |
| 실행 도움 | 무관하거나 실행 불가 | 미확인 안내/일반적 제안 | 질문에 맞는 구체적 행동/조회 결론 |
| 반복 | 같은 답을 새 답처럼 반복 | 불필요한 중복 | 중복 제거/미표시 주제/종료 안내 |

조건이 없는 숫자 조회 등에는 적용되지 않는 항목을 채점하지 않는다. 서로 다른 질문의 적용 항목이 달라 전체를 단일 품질 점수로 합치지 않았다.

## 사례 12건

| 사례 | 이전 → 개선 | 직접 확인한 근거와 한계 |
|---|---|---|
| `reported:1` 체력+체젠 | 요청 충족 0→2, 사실 2→2 | 문도/오공 카드 lv1 체력 640/610, 체젠 7/3.5 모두 표시. 체젠은 5초당. 화면의 중복 문장도 제거. |
| `ordered:1` 체젠·체력·마저 | 요청 충족 0→2 | 사용자가 말한 순서대로 세 항목이 나오고 실제 카드 행의 수치가 맞음. |
| `clauses:1` 비교+아리 E 쿨 | 요청 충족 0→2, 사실 0→2 | 이전은 세 챔피언의 E를 비교했음. 개선은 두 명 체력 비교와 아리 E 12초로 각각 답함. |
| `same-spell:1` 같은 E 쿨+사거리 | 요청 충족 1→2 | 본문에는 원래 두 사실이 있었지만 카드 중복 키가 뒤 카드를 버렸음. 이제 12초·975의 두 카드와 저장 기록이 모두 남음. |
| `spell-advice:1` 쿨+E 없는 제드 궁 대응 | 조건 0→2, 실행 도움 0→1 | 기존 CC 조언은 아리의 유일한 강한 CC인 E가 부재인 조건과 맞지 않음. 개선은 미확인 안내로 멈춤. 다른 실전 대안을 추가한 것은 아님. |
| `partial-guide:1` 체력+승리 보장 | 요청 충족 0→2, 실행 도움 1→2 | 지원하는 숫자는 답하고 승리 보장 부분만 제한. 질문과 무관한 결제/계정 안내 대신 라인전 질문 예시를 제안. |
| `pair-return:4` 한 상대→스탯→둘 다 아이템 | 요청 충족 0→2 | 럼블을 잃지 않고 두 상성으로 복귀. 마법 피해 분류와 MR 저항 조언을 유지. 추천이 모든 상황의 최적 아이템이라는 의미는 아님. |
| `conditions-return:4` 제드/럭스 조건 복원 | 요청 충족 0→2, 조건 1→2 | 제드전 E down과 럭스전 R down을 서로 섞지 않음. 저장 기록 복원 뒤에도 동일함. |
| `conditions-interleave:3` E 복귀·R 부재 | 조건 2→2, 실행 도움 2→2 | 기존에 이미 잘 되던 사례. 제드 표식 동안 아리 E 매혹으로 콤보를 끊는 상대 관점 노트를 유지. R 사용을 요구하지 않음. |
| `actionable:1` 오공으로 럼블/모데 | 요청 충족·실행 도움 2→2 | 럼블 작살 두 번째 타격 전 거리 벌리기, 모데 E 정면에서 간격 벌리기. 수치 표로 바꾸지 않음. 기존 구체 조언 유지. |
| `continuation:2` 팁 반복 | 반복 2→2 | 이미 표시한 주제를 재답변하지 않고 모두 보여줬다는 안내를 유지. 노트가 적으면 종료가 빠를 수 있음. |
| 검증 `cooldown-return:3` “궁 대응은?” 생략 | 요청 충족 0→2, 실행 도움 0→2 | 내 E/R 상태 뒤에 물은 상대 궁 대응을 내 궁 설명으로 오독하지 않음. 최종 답은 제드 표식과 매혹으로 콤보를 끊는 노트에 연결됨. |

수치는 `public/data/26.19/llm` 챔피언 카드와 대조했고, 행동 조언은 기존 playing/against 노트 및 상성 자료와 대조했다. 자동 평가의 숫자 검사와 별도로 체젠 단위, 질문의 스킬 주인, 직접 행동 요구를 읽었다. 신규 게임 지식이나 생성 답변을 추가하여 점수를 높이지 않았다.
