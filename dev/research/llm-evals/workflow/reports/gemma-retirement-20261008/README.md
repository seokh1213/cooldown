# Gemma 실험 종료와 정리, 2026-10-08

사용자의 결정으로 Gemma는 채택하지 않고 실험을 종료했다. 현행 Qwen 웨이트·배포 인덱스·제품 코드를 유지한다. 추가 모델 실험이나 학습을 진행 중인 것으로 남기지 않는다.

## 제거한 것과 보존한 것

로컬 `~/.cache/cooldown-kev/gemma-adapters-20261008`과 `gemma-diagnosis-20261008`의 어댑터·optimizer/RNG 체크포인트·평가 벡터·동결 학습 입력·원격 원본 아카이브를 삭제했다. 저장소의 `gemma-tuning-20261008/selected-adapter` 작업 사본과 Gemma 학습·비교 npm 명령 두 개도 제거했다. 정확한 파일 수·크기와 Qwen 보존 확인은 [cleanup.json](cleanup.json)에 있다.

실험 결과·질문별 예측·원문 스냅샷·프로토콜·입력과 가중치 해시·복구 검증 기록·평가 코드는 Git에 남긴다. `retrieval-v2` 질문 은행과 공통 회귀·분할·검색 평가·Colab 복구 테스트도 유지한다. 연구 코드 자체는 작고 테스트에서 사용하는 부분이 있어 기록으로 보존하며, npm 실행 메뉴에서는 제외했다.

이전 [학습 보고서](../gemma-tuning-20261008/README.md)의 `retention.json`과 [진단 보고서](../gemma-diagnosis-20261008/README.md)의 `retention.json`은 삭제 전 상태를 기록한 역사 자료다. 지금 백업이 존재한다는 뜻이 아니다. 해당 로컬 백업으로 같은 학습 상태를 이어가거나 동일 벡터의 점수를 재생할 수 없다. 삭제 전 선택 어댑터와 코드는 Git 커밋 `9c5c07a84`에 남아 있으며 Git 이력은 다시 쓰지 않았다.

## 남은 것은 선택 개선 두 가지

운영을 계속하기 위한 필수 후속 작업은 없다. 새 학습을 계속해야 한다는 결론도 아니다. 현행 Qwen에서도 확인한 두 병목을 개선하고 싶을 때 별도 범위로 진행한다.

1. **검색 보정의 순위 역전 줄이기.** 동일한 새 정답 질문 35개에서 Qwen 원시 1순위 정답 33개가 현행 보정 후 27개로 줄었다. 반대로 기존 269개는 213→266개로 늘므로 보정을 통째로 제거하지 않는다. 기존 성공과 새 원리 질문을 함께 지키는 조정만 채택한다.
2. **답변 가능성 판정을 검색 관련도와 분리하기.** 같은 새 질문에서 Qwen이 1순위로 찾은 정답 27개 중 15개가 임계값으로 거절됐다. 관련 문서를 찾았더라도 미래 승급 점수처럼 근거로 답할 수 없는 요청이 있다. 무작정 임계값을 내리거나 더 학습시키는 대신 근거가 요구를 충족하는지 따로 검증해야 한다.

이 수치는 이번 문서 검색 진단의 사후 분석이며 전체 챗봇 답변 정확도가 아니다. 두 개선 모두 효과가 보장된 상태가 아니며 기존 회귀와 새 질문을 함께 통과해야 한다. 이번 정리에서는 구현하지 않는다. 추가 개선 없이 현재 모델을 사용하는 선택도 유효하다.

## 정리 후 검증

Gemma 평가·복구 Python 테스트 12개, 공통 검색 평가 Node 테스트 2개, 품질 워크플로우 Node 테스트 19개가 통과했다. `npm run llm:test:audit`와 품질 inventory 게이트도 통과했다. 질문 은행·등록 회귀·수동 검수 지문의 해시는 정리 전과 동일하다. 삭제한 어댑터 두 파일은 inventory의 retired 목록으로 옮겼다.

현행 Qwen 배포 파일과 설정, `retrieval-v2` 질문 은행을 정리 전후 비교했다. 외부 Qwen 웨이트의 SHA-256도 일치한다. 이번 변경은 실험 자원과 실행 메뉴·문서 정리이며 제품 응답 로직·모델·데이터셋을 변경하지 않았다. 따라서 전체 모델 품질 점수를 새로 측정하거나 품질 향상을 주장하지 않는다.
