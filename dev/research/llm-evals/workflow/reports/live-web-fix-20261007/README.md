# 실제 웹에서 발견한 챗봇 오류 수정, 2026-10-07

이 보고서는 앞선 [실사용 비교](../live-web-20261007/README.md)에서 발견한 오류의 수정·재검사 기록이다. 이전 관찰을 덮어쓰지 않는다.

## 수정 범위

1. 추가 공격의 발사·취소 조건 뒤 새 적중 횟수를 물으면 이전 발사 상태를 지운다. 후속 횟수 질문에서는 미충족 조건도 설명한다. 처음 묻는 일반 평타 설명과 아이템 조회 후 돌아온 일반 설명은 보존한다.
2. `아 아니 추가 체력 42로 정정할게`처럼 자연어로 정정해도 직전 능력치 전환 계산을 이어 간다. 파이크 42→공격력 3, 98→7 및 블라디미르 90→주문력 3을 검증한다. 새 룬을 명시하면 룬 질문으로 전환한다.
3. 방관 약어와 `관통 30%` / `30% 관통` 표현을 같은 공식으로 처리한다. 문서의 적용 순서가 확인되어야 계산한다. 여러 대상 수치·여러 비율·음수·100% 초과·고정 관통의 % 표기는 계산하지 않는다.
4. `How should I lane as Ahri against Fizz?`는 앞선 방어력·마저 항목을 상속하지 않는다. 이어서 명시한 6레벨 방어력 비교는 정상 조회한다.
5. 능력치·레벨 앞의 챔피언 이름 오타도 기존 거리 기반 후보 처리에 포함한다. 하나로 확정되면 고치고 여러 후보면 확인한다. 화면의 오공으로 조용히 대체하지 않는다. 특정 오타 별칭을 추가하지 않았다.
6. 한국어 메커니즘 답변의 영문 능력치 이름을 표시 단계에서 번역한다. 계산식·수치와 승인 원문은 보존한다.
7. 참고 카드의 요약과 패시브 상세창은 상세 툴팁을 우선 표시한다. 26.19 아크샨 P의 한국어 summary는 3타를 물리 피해라고 적지만, 동일 패치 한·영 body와 승인 규칙은 마법 피해다. 원본 summary 자체를 수정하거나 승인 출처 해시를 바꾸지 않았다.
8. 가격 질문의 대화 본문 머리글에 가격을 표시한다. 장화는 자료 카드뿐 아니라 본문에도 `300 골드`를 표시한다.

질문별 고정 정답·챔피언별 실행 분기를 추가하지 않았다. 기존 도메인 근거를 읽는 조건 갱신·표현 해석·화면 표시를 수정했다. 새 모델 학습·웨이트 교체는 없다.

## 검증 이력과 판정

첫 전체 테스트는 빌드의 데이터 번들 쓰기와 동시에 실행해 일시적인 JSON 읽기 오류가 1건 발생했다. 해당 파일을 별도로 다시 실행해 7/7 통과했다. 이후 빌드는 데이터 번들을 다시 쓰지 않는 Vite 빌드로 실행했다.

1타 경계 보완 중 기존 일반 평타 설명이 좁아지는 부작용을 브라우저·메커니즘 검사로 발견했다. 이어 묻는 횟수 질문에만 해당 처리를 적용하고, 최초 설명 및 아이템 조회 후의 일반 설명을 별도 회귀 테스트로 보존했다. 중간에 소스가 바뀐 평가 세 개는 중단했으며 최종 품질 근거로 사용하지 않는다.

추가로 한국어 질문 1,947개를 훑어 능력치 앞 낱말의 새 오타 후보를 검사했다. 실제 이름 오타인 `가랜`은 보정하고, `아니`·`가면`·`직후`는 기존 기능어 제외 목록에 추가했다. `아니 체력도 같이`를 아리로 오인하던 중간 회귀는 오공·문도 체력/체젠 비교를 보존하도록 고쳤다. 최종 빌드의 실제 UI 3턴을 `guard-responses.json`과 `stat-correction.jpg`에 보존한다. 이 마지막 3턴은 모델 없이 쓰기 모드이며, 앞선 실제 모델 대화와 구분한다.

최종 측정·기존 은행과의 비교·정리 상태는 아래 최종 결과에 보존한다. 기존 request-scope 실패와 수동 판정 대상을 이 작업의 개선 실적으로 합산하지 않는다.
