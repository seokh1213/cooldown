# 챔피언 레벨별 수치 표시 전수 점검

2026-10-01, 현재 저장소의 26.19 데이터 기준. 173명 전원의 패시브·QWER와 변신 형태를 한국어·영어·중국어로 확인했다.

## 확인 범위

| 항목 | 수 |
| --- | ---: |
| 챔피언 | 173 |
| 언어 | 3 |
| 기본 스킬 항목: 173 × 5 × 3 | 2,595 |
| 형태별로 나눈 실제 설명 | 2,637 |
| 레벨별 수치가 있는 설명 | 573 |
| 설명에 연결된 레벨별 표 | 951 |

본문의 `[[si:scalelevel]]` 범위를 `levelValues`의 범위·퍼센트·표시 자릿수와 대조했다. 여러 번 등장하는 동일 범위는 표 하나로 처리하되, 여러 범위 중 일부만 빠진 경우도 검출한다. 변신 스킬에서는 화면이 실제로 사용하는 `forms`를 검사한다.

레벨 마커가 없는 수치 범위도 검토했다. 충전 시간, 이동 거리, 대상의 잃은 체력, 살아남은 자크 조각 수에 따른 범위는 챔피언 레벨 표 대상에서 제외했다. 판테온 W의 60~150과 쉬바나 Q의 10~200도 원본 BIN의 몬스터 피해 최솟값·상한값임을 확인했다.

## 발견한 누락과 수정

### 툴팁·상세 대화창의 변신 형태

| 챔피언·형태 | 누락 범위 | Lv 1 / 6 / 11 / 16 이후 |
| --- | --- | --- |
| 제이스 R · A 해머 → 캐논 | 방어력·마법 저항력 감소 | 20% / 25% / 30% / 35% |
| 제이스 R · B 캐논 → 해머 | 방어력·마법 저항력 기본 증가량 | 5 / 12 / 19 / 26 |
| 제이스 R · B 캐논 → 해머 | 다음 기본 공격의 기본 추가 피해 | 25 / 60 / 95 / 130 |
| 니달리 W · A 인간 | 동시에 설치할 수 있는 덫 개수 | 4 / 6 / 8 / 10 |

원본 수식의 레벨별 계산은 정상이다. 형태별 생성기가 HTML만 저장하면서 `levelValues`를 버렸고, 형태별 컴포넌트에도 표 렌더링이 없었다. 각 형태의 파싱 결과를 저장하고 해당 형태 설명 아래에 공통 표 컴포넌트를 연결했다. 세 언어에서 총 12개 표가 복구됐다.

### VS 화면의 펼친 스킬 설명

일반 스킬의 펼친 설명은 본문과 쿨타임만 표시했다. 이 때문에 **134명·188개 설명의 313개 표**가 한국어 기준으로 빠졌다. 패시브 115개와 액티브 스킬 설명 73개이며 오공 P·R, 벡스 P, 갈리오 W 등이 포함된다. 해당 경로에도 공통 레벨별 표를 연결했다. 툴팁에서 이미 정상인 일반 스킬도 이 펼친 설명에서는 표가 없었다.

## 수정 후 검증

- 전수 데이터 검사: 2,637개 설명과 951개 표에서 누락·본문과 연결되지 않은 표·잘못된 레벨 마커 0건.
- 브라우저 컴포넌트 전수 렌더링: 각 챔피언의 툴팁 내용과 VS 펼친 설명을 각각 생성. 5,190회 렌더링, 형태별 설명 5,274개, 표 1,902개에서 표 개수·형태 귀속·범위 라벨·첫 레벨 값 불일치 0건.
- 회귀 검사: 형태별 생성·디코딩, 173명 전수 데이터 검사, 제이스 R·니달리 W·벡스 P·오공 P/R의 실제 화면 표시를 자동 검사한다.
- 단위·데이터 검사 224개, 모바일·데스크톱 화면 검사 21개 통과. 타입 검사·린트·프로덕션 빌드 통과. 빌드의 기존 600KB 청크 크기 경고는 수정 전 HEAD 빌드에도 동일하게 발생함을 확인했다.

이 점검은 현재 생성된 설명의 레벨별 수치가 상세 표로 전달·표시되는지를 확인한다. 게임에 표시하지 않는 내부 계산값이나 전체 스킬 밸런스 수치의 정확성 검사는 별도 범위다.
